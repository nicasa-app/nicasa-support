# 疑難排解

## 常見問題

### 應用程式無法啟動

**現象**：Nicasa 啟動失敗或立刻當掉

**解決辦法**：
1. 確認系統為 macOS 10.13 或更高版本
2. 確認至少擁有 4GB 記憶體
3. 重新啟動你的 Mac
4. 從 Mac App Store 重新安裝 Nicasa
5. 檢查是否有衝突的應用程式

### 截圖無法使用

**現象**：截圖功能不運作

**解決辦法**：
1. **授予螢幕錄製權限**：
   - 進入 系統設定 > 隱私權與安全性 > 螢幕錄製
   - 勾選 Nicasa 旁邊的註記框
   - 重新啟動 Nicasa
2. 確認沒有其他截圖工具正在執行
3. 嘗試重新啟動你的 Mac

### Chrome 擴充功能無法使用

**現象**：擴充功能不顯示或無法擷取圖片

**解決辦法**：
1. 確認擴充功能已在 Chrome 中啟用
2. 檢查 Chrome 版本是否相容
3. 嘗試重新整理網頁
4. 重新安裝擴充功能
5. 清除瀏覽器快取與 Cookie

### 圖片無法載入

**現象**：縮圖不顯示或圖片打不開

**解決辦法**：
1. 檢查圖片檔案的存取權限
2. 確認圖片檔案未損壞
3. 確認格式受支援（JPEG、PNG、GIF、BMP、TIFF、WebP）
4. 嘗試重新開啟該檔案夾
5. 重新啟動 Nicasa

### 效能緩慢

**現象**：應用程式卡頓或縮圖載入很慢

**解決辦法**：
1. 關閉其他佔用記憶體較多的應用程式
2. 確保有充足的可用記憶體（建議 8GB）
3. 在偏好設定中調小縮圖格狀尺寸
4. 清理應用程式快取
5. 重新啟動你的 Mac

### AI 編輯器無法使用

**現象**：AI 編輯工具無法使用或不運作

**解決辦法**：
1. 確認網路連線穩定（部分功能需要連網）
2. 檢查你的 Mac 是否滿足最低需求
3. 重新啟動 Nicasa
4. 更新到最新版本
5. 如問題依舊，請聯絡支援

### 權限問題

**現象**：應用程式要求權限，或某些功能無法使用

**解決辦法**：
1. **螢幕錄製**：系統設定 > 隱私權與安全性 > 螢幕錄製
2. **輔助使用**：系統設定 > 隱私權與安全性 > 輔助使用（用於懸浮模式）
3. **檔案與檔案夾**：系統設定 > 隱私權與安全性 > 檔案與檔案夾
4. 授予權限後重新啟動 Nicasa

### 懸浮模式問題

**現象**：透明懸浮模式運作不正常

**解決辦法**：
1. 在系統設定中授予輔助使用權限
2. 確認沒有其他懸浮類工具正在執行
3. 嘗試關閉再重新開啟懸浮模式
4. 重新啟動 Nicasa

## 錯誤訊息

### 「需要螢幕錄製權限」

**解決辦法**：依上文「截圖無法使用」一節所述授予螢幕錄製權限。

### 「無法載入圖片」

**可能原因**：
- 檔案已損壞
- 格式不受支援
- 檔案權限問題
- 檔案過大

**解決辦法**：
1. 嘗試用「預覽程式」開啟該檔案，確認它是否有效
2. 轉換為受支援的格式
3. 檢查檔案權限
4. 確認為合理的檔案大小

### 「擴充功能沒有回應」

**解決辦法**：重新整理網頁後重試。如果反覆出現，請重新安裝擴充功能。

## 尋求協助

如果問題依然存在：

1. 查閱本疑難排解指南
2. 前往我們的[常見問題](/zh-TW/guide/faq)
3. 在 [GitHub](https://github.com/nicasa-app/nicasa-support/issues) 上提交 issue
4. 請附上你的 macOS 版本、Nicasa 版本以及重現問題的詳細步驟

## 系統資訊

回報問題時，請提供：

- macOS 版本（蘋果選單 > 關於這台 Mac）
- Nicasa 版本（Nicasa > 關於 Nicasa）
- Mac 機型與晶片（Apple 晶片或 Intel）
- 重現問題的步驟
- 任何錯誤訊息

這通常意味著圖片檔案已被移動或刪除。請嘗試重新開啟該檔案夾或選擇其他目錄。

### 「不支援的格式」

無法辨識該圖片格式。請查看[支援的格式](/zh-TW/guide/usage)清單，或將圖片轉換為相容格式。

### 「記憶體不足」

系統可用記憶體不足。請關閉其他應用程式，或升級你的記憶體。

## 進階疑難排解

### 查看日誌

存取應用程式日誌：

1. 進入 輔助說明 > 顯示日誌
2. 或在以下位置尋找日誌：
   - Windows：`%APPDATA%\Nicasa\logs`
   - macOS：`~/Library/Application Support/Nicasa/logs`
   - Linux：`~/.config/Nicasa/logs`

### 重設應用程式

將所有設定回復為預設值：

1. 關閉 Nicasa
2. 刪除應用程式資料檔案夾
3. 重新啟動 Nicasa

### 命令列選項

面向進階使用者，Nicasa 支援命令列參數：

```bash
nicasa --verbose          # 啟用詳細日誌
nicasa --reset-settings   # 重設所有設定
nicasa /path/to/folder    # 開啟指定檔案夾
```
