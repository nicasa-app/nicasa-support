# 常見問題

## 一般問題

### Nicasa 是什麼？

Nicasa 是一款專為 macOS 打造的現代桌面圖片檢視與截圖工具。它以乾淨、反應迅速的介面提供快速直觀的圖片瀏覽，並具備強大的 AI 編輯能力。

### Nicasa 免費嗎？

Chrome 擴充功能完全免費，可隨意下載使用。macOS 應用程式需一次性支付 $4.99，才能解鎖全部功能。

### 支援哪些作業系統？

Nicasa 目前僅支援 macOS 10.13 或更高版本，暫不提供 Windows 與 Linux 版本。

### 如何更新 Nicasa？

更新透過 Mac App Store 進行。有新版本時會收到通知，也可以直接在 App Store 應用程式中更新。

## 使用問題

### 如何用 Nicasa 截圖？

1. 啟動 Nicasa
2. 點擊工具列中的截圖按鈕，或使用 `Cmd+S`
3. 選取你想要擷取的區域
4. 截圖會在 Nicasa 中開啟，可立即編輯

### Nicasa 能處理網頁圖片嗎？

可以！安裝免費的 Nicasa Chrome 擴充功能即可：
- 在一個地方檢視任意網站的所有圖片
- 隨時擷取並瀏覽圖片
- 直接在 Nicasa 中開啟圖片，獲得更佳的檢視體驗

### 有哪些 AI 編輯功能？

Nicasa 內建強大的 AI 工具：
- **自動增強**：自動提升畫質
- **智慧裁切**：智慧裁切建議
- **影像修復**：智慧去除不需要的物體
- **色彩校正**：由 AI 驅動的色彩調整
- **降噪**：去除雜點與顆粒

### 透明懸浮模式是如何運作的？

為設計師與繪師量身打造：
- 把圖片以可調透明度置頂於所有視窗之上
- 可用於描圖、參考對照或 UI 比對
- 在所有應用程式中保持位置不變

## 技術問題

### 為什麼需要授予螢幕錄製權限？

截圖功能需要螢幕錄製權限，這樣 Nicasa 才能在你使用截圖工具時擷取螢幕。

### 可以離線使用 Nicasa 嗎？

可以。macOS 應用程式可完全離線處理本機圖片檔案；透過 Chrome 擴充功能擷取網頁圖片則需要網路連線。

### 支援哪些 macOS 版本？

Nicasa 支援 macOS 10.13 或更高版本，並針對 Apple 晶片最佳化，在 M 系列晶片上原生執行。

### Chrome 擴充功能需要哪些權限？

該擴充功能僅為擷取圖片位址而請求讀取頁面內容，不會讀取或儲存瀏覽記錄。

### 我的資料會被上傳嗎？

不會。所有處理都在你的裝置本機完成，Nicasa 不會蒐集、傳輸或儲存你的圖片。

### 如何備份我的設定？

設定儲存在本機。備份方法：
1. 進入 Nicasa > 偏好設定
2. 如支援，匯出你的設定
3. 或手動備份應用程式偏好設定檔案夾

設定儲存在應用程式資料檔案夾中，複製該檔案夾即可完成備份。

### 有可攜版嗎？

Windows 版本提供可攜版，可從我們的網站下載。

## 開發問題

### 我可以為 Nicasa 貢獻程式碼嗎？

前往我們的 [GitHub 儲存庫](https://github.com/nicasa-project/nicasa-support)，貢獻程式碼、回報問題或提出功能建議。

### 如何從原始碼建構 Nicasa？

請參閱 GitHub 上的開發者文件以取得建構說明。

### Nicasa 使用了哪些技術？

Nicasa 使用現代 Web 技術建構，桌面端封裝使用 Electron，介面使用 Vue.js。

## 隱私權問題

### Nicasa 會蒐集任何資料嗎？

不會。Nicasa 不蒐集也不傳輸任何個人資料，所有圖片處理都在你的裝置本機完成。

### 我的圖片安全嗎？

安全。Nicasa 只會存取你主動開啟的圖片，不會上傳或分享你的檔案。

### Nicasa 需要哪些權限？

Nicasa 需要存取檔案系統以讀取圖片和儲存設定，執行時不依賴網路。
