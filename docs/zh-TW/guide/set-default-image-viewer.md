# 將 Nicasa 設為預設看圖應用程式

依照以下簡單步驟，讓圖片預設用 Nicasa 開啟。

## 第 1 步 —— 按右鍵點擊圖片檔案
在 Finder 中找到任意 HEIC/HEIF 圖片並按右鍵點擊它。

提示：按右鍵點擊任意 HEIC/HEIF 圖片檔案。

## 第 2 步 —— 選擇「打開方式」
在快速選單中停留在「打開方式」上。

提示：停留在「打開方式」上。

## 第 3 步 —— 選擇 Nicasa
在應用程式清單中選擇 Nicasa。

提示：選擇「Nicasa」。

## 第 4 步 —— 勾選「始終以此方式打開」
在對話框中勾選「始終以此方式打開」，然後點擊「打開」。

提示：勾選「始終以這種方式打開 .heic 檔案」。

## 第 5 步 —— 設定完成！
從現在起，你的圖片都會用 Nicasa 開啟。

提示：設定完成！盡情享受 Nicasa 吧。

## 第 6 步 —— 隨時更改預設應用程式（選用）
日後如需更換預設應用程式：

按右鍵點擊任意圖片 → 顯示簡介 → 打開方式 → 全部更改

提示：隨時在 Finder 中更改：顯示簡介 → 打開方式 → 全部更改

![macOS：將 Nicasa 設為預設看圖應用程式](/guide.png)

**注意**
如果在清單中找不到 Nicasa，請確認 Nicasa 已正確安裝。你可能需要重新啟動 Nicasa 後再試一次。
