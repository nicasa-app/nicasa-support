# 使用指南

## 基礎導覽

### 開啟圖片

- **檔案選單**：點擊 檔案 > 開啟，選取單張圖片
- **檔案夾檢視**：點擊 檔案 > 開啟檔案夾，瀏覽整個目錄
- **拖放**：把圖片檔案或檔案夾直接拖到應用程式視窗中
- **Chrome 擴充功能**：在任意網站上點擊擴充功能圖示即可檢視全部圖片

## Finder 同步擴充功能

### 在 Finder 中快速處理圖片

Finder 同步擴充功能會在 Finder 工具列中加入一個 Nicasa 按鈕，用於快速處理圖片：

1. 在 Finder 中選取一張或多張圖片
2. 點擊 Nicasa 工具列按鈕
3. 選擇 **圖片最佳化工具** 以壓縮檔案，或選擇 **AI 影像編輯器** 以增強圖片
4. Nicasa 會自動開啟並處理選取的檔案

### 支援的格式

該擴充功能支援：JPG、PNG、GIF、BMP、WebP、SVG、TIFF 和 ICO 檔案。

### 縮圖檢視

主介面以縮圖形式展示你的圖片：

- **單擊**：選取一張圖片
- **連按兩下**：以完整檢視開啟
- **按右鍵**：呼出帶選項的快速選單

### 完整檢視模式

在全螢幕檢視圖片時：

- **縮放**：使用滑鼠滾輪或縮放控制項
- **平移**：在放大後的圖片上按住拖曳
- **切換**：使用方向鍵或螢幕按鈕切換到上一張/下一張

## 截圖功能

### 截圖

1. 點擊工具列中的截圖按鈕，或使用鍵盤快速鍵
2. 選取你想要擷取的區域
3. 截圖會自動在 Nicasa 中開啟，方便立即編輯

### 螢幕錄製權限

截圖功能需要螢幕錄製權限：

1. 進入 系統設定 > 隱私權與安全性 > 螢幕錄製
2. 勾選 Nicasa 旁邊的註記框
3. 如有必要，重新啟動 Nicasa

## AI 影像編輯器

### AI 編輯器概覽

Nicasa 內建強大的 AI 影像增強工具：

- **自動增強**：自動提升畫質
- **智慧裁切**：智慧給出裁切建議
- **色彩校正**：由 AI 驅動的色彩調整
- **降噪**：去除雜點與顆粒
- **銳化**：智慧銳化且不產生偽影

### 影像修復（Inpainting）工具

修復工具可以幫你：

- 去除圖片中不需要的物體
- 智慧填補缺失部分
- 修復受損區域
- 清理背景

## 透明懸浮模式

為設計師與繪師量身打造：

1. 在 Nicasa 中開啟一張圖片
2. 從「顯示方式」選單啟用懸浮模式
3. 使用滑桿調節透明度
4. 圖片將始終浮於所有其他視窗之上
5. 可用於描圖、參考對照或 UI 比對

## 鍵盤快速鍵

| 快速鍵 | 動作 |
|----------|--------|
| `Cmd+O` | 開啟檔案 |
| `Cmd+Shift+O` | 開啟檔案夾 |
| `Space` | 下一張圖片 |
| `Shift+Space` | 上一張圖片 |
| `Cmd+F` | 切換全螢幕 |
| `Cmd+W` | 關閉視窗 |
| `Cmd+Q` | 結束應用程式 |
| `Delete` | 刪除目前圖片 |
| `Cmd+S` | 截圖 |
| `Cmd+E` | 開啟 AI 編輯器 |
| `Cmd+T` | 切換懸浮模式 |

## Chrome 擴充功能整合

### 安裝

1. 安裝 [Nicasa Chrome 擴充功能](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. 擴充功能圖示會出現在瀏覽器工具列中

### 使用

1. 開啟任意網站
2. 點擊 Nicasa 擴充功能圖示
3. 以格狀形式檢視該頁面的所有圖片
4. 點擊任意圖片，即可在 Nicasa 中開啟
5. 對網頁圖片使用 Nicasa 的全部功能

## 設定

透過 Nicasa > 偏好設定進入設定：

- **一般**：預設檔案夾、語言、主題
- **檢視**：縮圖尺寸、縮放行為、動畫
- **編輯器**：AI 工具偏好、預設增強項目
- **擴充功能**：Chrome 擴充功能設定
- **隱私權**：資料蒐集偏好

## 支援的格式

Nicasa 支援所有常見圖片格式：

- **標準格式**：JPEG、PNG、GIF、BMP、TIFF、WebP
- **RAW**：CR2、NEF、ARW、DNG（需轉換）
- **向量**：SVG（需點陣化）
- **動態圖片**：GIF、APNG

- JPEG/JPG
- PNG
- GIF（靜態）
- BMP
- TIFF
- WebP
- HEIC（在受支援的系統上）

## 技巧與提示

- 使用搜尋列按檔案名稱快速尋找圖片
- 透過檔案夾整理圖片來建立圖集
- 使用評分系統標記你喜歡的圖片
- 透過「檔案」選單以不同格式匯出圖片
