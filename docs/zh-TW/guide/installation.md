# 安裝

## 下載 Nicasa

Nicasa 僅透過 Mac App Store 提供 macOS 版本。應用程式售價 $4.99，一次性購買即可解鎖全部功能。

### 下載方式

- **Mac App Store**：[下載 Nicasa](https://apps.apple.com/us/app/nicasa-image-viewer/id6756032669?mt=12) —— $4.99
- **Chrome 擴充功能**：[免費 Chrome 擴充功能](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj) —— 免費

## 安裝步驟

### 透過 Mac App Store 安裝

1. 點擊上面的「下載 Nicasa」連結，或在 Mac App Store 中搜尋「Nicasa」
2. 點擊「取得」或「購買」完成付費（$4.99）
3. 應用程式會自動下載並安裝
4. 從「應用程式」檔案夾或啟動台啟動 Nicasa

### 安裝 Chrome 擴充功能

1. 前往 [Chrome 線上應用程式商店頁面](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. 點擊「加到 Chrome」
3. 在彈出視窗中確認安裝
4. 擴充功能即會加入你的瀏覽器

## 首次啟動

第一次啟動 Nicasa 時：

1. 系統會提示你授予必要權限（截圖功能需要螢幕錄製權限）
2. 應用程式會掃描「圖片」檔案夾中的圖片
3. 你可以立即開始瀏覽圖庫
4. 建議安裝 Chrome 擴充功能，以獲得更完整的網頁看圖體驗

### Finder 同步擴充功能

Nicasa 附帶一個 Finder 工具列擴充功能，用於快速處理圖片：

1. 啟動 Nicasa 後，進入**系統設定** → **擴充功能** → **Finder 擴充功能**
2. 啟用 **Nicasa Finder Sync**
3. 在 Finder 工具列上按右鍵 → **自訂工具列…**
4. 把 Nicasa 按鈕拖到工具列上

這樣你就能直接在 Finder 裡對選取的圖片進行最佳化或編輯。

## 系統需求

- **macOS**：10.13 或更高版本
- **儲存空間**：54.5 MB 可用空間
- **記憶體**：最低 4GB RAM，建議 8GB

## 權限

Nicasa 需要以下權限：

- **螢幕錄製**：用於截圖功能（可稍後授予）
- **輔助使用**：用於懸浮模式相關功能（選用）
- **檔案與檔案夾**：存取「圖片」檔案夾及使用者選取的目錄

你可以隨時在「系統設定 > 隱私權與安全性」中修改這些權限。

## 安裝疑難排解

如果安裝過程中遇到問題：

- 確認你擁有管理者/root 權限
- 檢查系統是否滿足最低需求
- 嘗試重新下載安裝檔
- 如在 Linux 上安裝，請確認已安裝所需相依套件

如需更多協助，請前往我們的[問題回報頁](https://github.com/nicasa-project/nicasa-support/issues)。
