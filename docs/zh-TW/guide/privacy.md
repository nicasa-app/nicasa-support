# 隱私權政策

## 資料蒐集

開發者不會透過本應用程式蒐集任何資料。

### 我們不會蒐集的資訊

- 個人資訊
- 使用統計
- 裝置資訊
- 位置資料
- 圖片內容或中繼資料
- 瀏覽記錄
- 任何其他使用者資料

### Chrome 擴充功能

Nicasa Chrome 擴充功能僅為實現看圖功能而請求存取頁面內容以擷取圖片位址。該擴充功能：

- 不會讀取或儲存瀏覽記錄
- 不會追蹤使用者行為
- 不會向外部伺服器傳輸任何資料
- 僅在瀏覽器本機處理圖片位址

### 本機處理

所有圖片處理、編輯與檢視都在你的裝置本機完成，不會把圖片或資料上傳到外部伺服器。

### 權限

Nicasa 在 macOS 上請求以下權限：

- **螢幕錄製**：截圖功能所必需
- **輔助使用**：選用，用於懸浮模式相關功能
- **檔案與檔案夾**：存取使用者選取的目錄以瀏覽圖片

這些權限可在「系統設定 > 隱私權與安全性」中管理。

### 第三方服務

Nicasa 未整合任何第三方統計、廣告或資料蒐集服務。

### 隱私選項

如果你想行使隱私權權利（例如：查閱、刪除、可攜或拒絕授權等請求），或你確信 Nicasa 持有關於你的個人資料，可透過以下任一方式提交請求：

- 電子郵件：nicasa@w3cub.com
- 提交隱私 issue：https://github.com/nicasa-app/nicasa-support/issues
- 使用我們的隱私選項頁面：/zh-TW/guide/privacy-choices

由於如上所述 Nicasa 並不蒐集個人資料，許多請求會以「未持有任何個人資料」的確認作為回覆。如果未來的版本開始蒐集個人資料，本頁面與隱私選項表單將提供提交與追蹤請求的途徑。

我們力求在 30 天內回應合理的隱私請求。

### 更新

本隱私權政策可能會隨應用程式新版本而更新。如有重大變更，我們會通知使用者。

### 聯絡我們

如對隱私權有疑問，請透過 [GitHub 儲存庫](https://github.com/nicasa-app/nicasa-support/issues)聯絡我們。
