# 螢幕錄製權限指南（macOS）

## 為什麼 Nicasa 需要螢幕錄製權限？

在 macOS 上，截圖與螢幕擷取類應用程式必須取得螢幕錄製權限，才能讀取顯示器上的像素。

從 macOS 10.15 Catalina 開始，Apple 導入了更嚴格的隱私權保護。任何擷取螢幕內容（包括截圖）的應用程式都必須取得使用者的明確授權。

這適用於所有應用程式，包括從 Mac App Store 下載的應用程式。

**沒有該權限，Nicasa 無法截圖或錄製螢幕內容。**

## 如何開啟螢幕錄製權限

請依下列步驟操作：

1. 開啟 **系統設定**
2. 進入 **隱私權與安全性**
3. 選擇 **螢幕錄製**
4. 在清單中找到 **Nicasa** 並勾選

如果應用程式當時已在執行，請在授予權限後重新啟動 Nicasa。

## 如果權限提示沒有出現

權限對話框通常會在應用程式首次嘗試擷取螢幕時出現。

如果你沒有看到該提示，可能是因為：

- 權限請求先前被拒絕過
- macOS 快取了權限狀態
- 應用程式在對話框出現之前就執行了擷取

這種情況下，你可能需要重設該權限。

## 重設螢幕錄製權限

你可以在終端機中使用以下指令重設權限：

```bash
tccutil reset ScreenCapture com.nicasa.nue
```

執行指令後：

1. 重新啟動 Nicasa
2. 再次觸發截圖功能
3. macOS 應會重新顯示權限對話框

## 如果重設仍然無效

極少數情況下，macOS 可能會保留無效的權限狀態。

如果重設權限沒有解決問題，請嘗試以下步驟：

1. 結束 Nicasa
2. 從「應用程式」檔案夾中刪除 Nicasa
3. 從 Mac App Store 重新安裝最新版本
4. 再次啟動應用程式
5. 當 macOS 要求螢幕錄製權限時，選擇 **允許**

重新安裝應用程式可以促使 macOS 重建權限記錄。

## 另一種手動修復方法

你也可以手動切換一次權限：

1. 開啟 **系統設定**
2. 進入 **隱私權與安全性**
3. 開啟 **螢幕錄製**
4. 取消勾選 Nicasa，然後重新勾選
5. 重新啟動 Nicasa

## 安全性說明

授予螢幕錄製權限並不會讓 Nicasa 控制你的系統。

它僅允許應用程式為截圖與擷取功能讀取螢幕像素。

你可以隨時在以下位置撤銷該權限：
**系統設定 → 隱私權與安全性 → 螢幕錄製**
