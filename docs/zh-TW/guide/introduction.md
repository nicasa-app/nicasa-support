# 簡介

## 關於 Nicasa

Nicasa 是一款現代桌面圖片檢視與截圖工具，以速度、簡潔和強大的編輯能力為設計目標。它專為 macOS 打造，把順暢、現代的看圖體驗帶到你的桌面。

## 核心功能

### 🖼️ **更好的看圖方式**
乾淨專注的介面讓圖片瞬間呈現。沒有干擾，沒有雜亂——只有你的內容，在開啟的那一刻被優雅地呈現。

### 📸 **截圖與擷取**
幾秒內截取螢幕任意區域。快速而精確的截圖工具內建於 Nicasa，儲存與分享視覺靈感從未如此簡單。

### 🤖 **AI 影像編輯**
用強大的 AI 工具增強與修飾圖片。從快速調整到智慧編輯，Nicasa 幫你輕鬆完成影像變身。

### 🔍 **透明懸浮模式**
設計師與繪師的利器：把圖片置頂於所有視窗之上，並可調整透明度——非常適合描圖、參考對照和 UI 比對。

### 🌐 **Chrome 擴充功能整合**
與 Nicasa Chrome 擴充功能無縫銜接，在一個介面裡檢視任意網站上的全部圖片。隨時擷取、瀏覽並直接在 Nicasa 中開啟圖片，獲得更快、更沉浸的看圖體驗。

### 🎨 **順暢直觀的設計**
由新世代技術驅動，Nicasa 帶來流暢的轉場、清晰的算繪和體貼的互動設計。

## 系統需求

- **作業系統**：macOS 10.13 或更高版本
- **記憶體**：最低 4GB RAM，建議 8GB
- **儲存空間**：安裝需要 54.5 MB
- **顯示**：最低 1280x720 解析度

## 支援的語言

Nicasa 支援多種語言，包括英語、簡體中文、繁體中文、日語、法語、韓語、德語、西班牙語、義大利語、越南語、泰語、印地語、土耳其語、俄語、葡萄牙語、荷蘭語、德語（瑞士）、芬蘭語、馬來語、希臘語、挪威語、印尼語、匈牙利語、丹麥語和烏克蘭語。
