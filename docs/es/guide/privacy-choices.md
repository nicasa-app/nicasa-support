# Opciones de privacidad

Esta página describe cómo enviar solicitudes de privacidad a Nicasa y qué puedes esperar.

## Para qué sirve

Utiliza esta página para solicitar acceso a datos personales, solicitar su eliminación, solicitar portabilidad u oponerte a determinados usos de datos (por ejemplo, solicitudes de «No vender» cuando corresponda).

Nota: actualmente Nicasa no recopila ni almacena datos personales (consulta la Política de privacidad). Si crees que tenemos datos personales sobre ti, envía una solicitud y lo investigaremos.

## Cómo enviar una solicitud

Proporciona la siguiente información al hacer una solicitud para ayudarnos a procesarla con eficacia:

- Tu nombre
- Correo electrónico de contacto
- Descripción de la solicitud (acceso, eliminación, portabilidad u oposición)
- Cualquier identificador que nos ayude a localizar registros (por ejemplo, el ID de un ticket de soporte)

Envía las solicitudes a uno de los siguientes canales:

- Correo electrónico: nicasa@w3cub.com
- Abrir una incidencia de privacidad: https://github.com/nicasa-app/nicasa-support/issues

## Tiempo de respuesta

Nuestro objetivo es acusar recibo y responder a las solicitudes válidas en un plazo de 30 días. Si necesitamos más tiempo, te lo notificaremos con un plazo estimado.

## Si no disponemos de datos personales

Dado que Nicasa está diseñada para procesar imágenes localmente y no recopilar datos de usuario, muchas solicitudes se cerrarán confirmando que no se dispone de datos personales. Si aportas pruebas de que se recopilaron datos personales, lo investigaremos y tomaremos las medidas oportunas.

## No vender / Oposición

Si estás ejerciendo un derecho de tu jurisdicción (por ejemplo, conforme a la CCPA/CPRA) para oponerte a la venta, y crees que hemos vendido tus datos personales, describe las circunstancias en tu solicitud. Si no vendemos datos personales, lo confirmaremos en nuestra respuesta.

## Contacto

Si tienes preguntas sobre este proceso, escribe a nicasa@w3cub.com o abre una incidencia en https://github.com/nicasa-app/nicasa-support/issues.
