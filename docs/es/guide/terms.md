# Términos del servicio

## Aceptación de los términos

Al descargar, instalar o usar Nicasa (la «App»), aceptas quedar vinculado por estos Términos del servicio (los «Términos»). Si no estás de acuerdo con estos Términos, no uses la App.

## Descripción del servicio

Nicasa es un visor de imágenes de escritorio y una herramienta de captura de pantalla para macOS que ofrece:

- Funciones de visualización y navegación de imágenes
- Funcionalidad de captura de pantalla
- Herramientas de edición de imágenes con IA
- Extensión de navegador Chrome para extraer imágenes web
- Modo superposición transparente para trabajos de diseño
