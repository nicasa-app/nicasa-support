# Preguntas frecuentes

## Preguntas generales

### ¿Qué es Nicasa?

Nicasa es un visor de imágenes de escritorio moderno y una herramienta de captura de pantalla diseñada exclusivamente para macOS. Ofrece una navegación rápida e intuitiva por tus colecciones de imágenes con una interfaz limpia y ágil, además de potentes capacidades de edición con IA.

### ¿Nicasa es gratis?

La extensión de Chrome es totalmente gratuita. La app para macOS requiere una compra única de 4,99 $ para acceder a todas las funciones.

### ¿Qué sistemas operativos son compatibles?

Actualmente Nicasa solo está disponible para macOS 10.13 o posterior. Por el momento no hay versiones para Windows ni Linux.

### ¿Cómo actualizo Nicasa?

Las actualizaciones se gestionan a través del Mac App Store. Recibirás notificaciones cuando haya actualizaciones disponibles y podrás actualizar directamente desde la app App Store.

## Preguntas de uso

### ¿Cómo hago capturas de pantalla con Nicasa?

1. Abre Nicasa
2. Haz clic en el botón de captura de la barra de herramientas o usa `Cmd+S`
3. Selecciona el área que quieres capturar
4. La captura se abrirá en Nicasa para editarla de inmediato

### ¿Nicasa funciona con imágenes web?

¡Sí! Instala la extensión de Chrome gratuita de Nicasa para:
- Ver todas las imágenes de cualquier sitio web en un solo lugar
- Extraer y explorar imágenes al instante
- Abrir imágenes directamente en Nicasa para una mejor visualización

### ¿Qué funciones de edición con IA hay disponibles?

Nicasa incluye potentes herramientas de IA:
- **Mejora automática**: mejora la calidad de la imagen automáticamente
- **Recorte inteligente**: sugerencias inteligentes de recorte
- **Relleno**: elimina objetos no deseados de forma inteligente
- **Corrección de color**: ajustes de color impulsados por IA
- **Reducción de ruido**: elimina el ruido y el grano

### ¿Cómo funciona el modo superposición transparente?

Perfecto para diseñadores y artistas:
- Fija imágenes por encima de todas las ventanas con transparencia ajustable
- Úsalo para calcar, consultar referencias o comparar interfaces
- Mantiene la posición en todas las aplicaciones

## Preguntas técnicas

### ¿Por qué necesito conceder el permiso de grabación de pantalla?

El permiso de grabación de pantalla es necesario para la función de captura. Permite a Nicasa capturar tu pantalla cuando usas la herramienta de captura.

### ¿Puedo usar Nicasa sin conexión?

Sí. La app para macOS funciona completamente sin conexión con archivos de imagen locales. La extracción de imágenes web mediante la extensión de Chrome requiere conexión a internet.

### ¿Qué versiones de macOS son compatibles?

Nicasa es compatible con macOS 10.13 o posterior. Está optimizada para Apple Silicon y se ejecuta de forma nativa en chips de la serie M.

### ¿Qué permisos necesita la extensión de Chrome?

La extensión solicita acceso al contenido de la página únicamente para extraer las URL de las imágenes. No lee ni almacena el historial de navegación.

### ¿Se suben mis datos a algún lugar?

No. Todo el procesamiento ocurre localmente en tu dispositivo. Nicasa no recopila, transmite ni almacena tus imágenes.

### ¿Cómo hago una copia de seguridad de mis ajustes?

Tus ajustes se guardan localmente. Para hacer una copia de seguridad:
1. Ve a Nicasa > Preferencias
2. Exporta tus ajustes si está disponible
3. O haz una copia manual de la carpeta de preferencias de la aplicación

Los ajustes se guardan en la carpeta de datos de la aplicación. Copia esa carpeta para respaldar tus preferencias.

### ¿Existe una versión portátil?

Hay una versión portátil disponible para Windows. Descárgala desde nuestro sitio web.

## Preguntas de desarrollo

### ¿Puedo contribuir a Nicasa?

Visita nuestro [repositorio de GitHub](https://github.com/nicasa-project/nicasa-support) para contribuir con código, informar de problemas o sugerir funciones.

### ¿Cómo compilo Nicasa desde el código fuente?

Consulta nuestra documentación para desarrolladores en GitHub para obtener las instrucciones de compilación.

### ¿Qué tecnologías usa Nicasa?

Nicasa está creada con tecnologías web modernas, incluido Electron para el contenedor de escritorio y Vue.js para la interfaz.

## Preguntas de privacidad

### ¿Nicasa recopila algún dato?

No, Nicasa no recopila ni transmite ningún dato personal. Todo el procesamiento de imágenes ocurre localmente en tu dispositivo.

### ¿Mis imágenes están seguras?

Sí. Nicasa solo accede a las imágenes que abres explícitamente. No sube ni comparte tus archivos.

### ¿Qué permisos necesita Nicasa?

Nicasa necesita acceso al sistema de archivos para leer imágenes y guardar ajustes. No requiere conexión a internet para funcionar.
