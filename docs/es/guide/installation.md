# Instalación

## Descargar Nicasa

Nicasa está disponible exclusivamente para macOS a través del Mac App Store. La app cuesta 4,99 $ y ofrece una compra única con acceso a todas las funciones.

### Opciones de descarga

- **Mac App Store**: [Descargar Nicasa](https://apps.apple.com/us/app/nicasa-image-viewer/id6756032669?mt=12) —— 4,99 $
- **Extensión de Chrome**: [Extensión de Chrome gratuita](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj) —— Gratis

## Pasos de instalación

### Instalación desde el Mac App Store

1. Haz clic en el enlace «Descargar Nicasa» de arriba o busca «Nicasa» en el Mac App Store
2. Haz clic en «Obtener» o «Comprar» para adquirir la app (4,99 $)
3. La app se descargará e instalará automáticamente
4. Abre Nicasa desde la carpeta Aplicaciones o el Launchpad

### Instalación de la extensión de Chrome

1. Visita la [página de Chrome Web Store](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. Haz clic en «Añadir a Chrome»
3. Confirma la instalación en la ventana emergente
4. La extensión se añadirá a tu navegador

## Primer inicio

Al abrir Nicasa por primera vez:

1. Se te pedirá que concedas los permisos necesarios (grabación de pantalla para las capturas)
2. La aplicación buscará imágenes en tu carpeta Imágenes
3. Puedes empezar a explorar tu colección de inmediato
4. Considera instalar la extensión de Chrome para mejorar la navegación web

### Extensión de sincronización con el Finder

Nicasa incluye una extensión de la barra de herramientas del Finder para procesar imágenes rápidamente:

1. Tras abrir Nicasa, ve a **Ajustes del Sistema** → **Extensiones** → **Extensiones del Finder**
2. Activa **Nicasa Finder Sync**
3. Haz clic derecho en la barra de herramientas del Finder → **Personalizar barra de herramientas…**
4. Arrastra el botón de Nicasa para añadirlo a la barra

Así podrás optimizar o editar las imágenes seleccionadas directamente desde el Finder.

## Requisitos del sistema

- **macOS**: 10.13 o posterior
- **Almacenamiento**: 54,5 MB de espacio disponible
- **Memoria**: 4 GB de RAM mínimo, 8 GB recomendados

## Permisos

Nicasa requiere los siguientes permisos:

- **Grabación de pantalla**: para la función de captura (se puede conceder más tarde)
- **Accesibilidad**: para las funciones del modo superposición (opcional)
- **Archivos y carpetas**: acceso a la carpeta Imágenes y a los directorios elegidos por el usuario

Puedes modificar estos permisos en cualquier momento en Ajustes del Sistema > Privacidad y seguridad.

## Solución de problemas de instalación

Si encuentras problemas durante la instalación:

- Asegúrate de tener privilegios de administrador/root
- Comprueba que tu sistema cumple los requisitos mínimos
- Intenta descargar el archivo de nuevo
- En Linux, asegúrate de tener instaladas las dependencias necesarias

Para más ayuda, visita nuestra [página de incidencias](https://github.com/nicasa-project/nicasa-support/issues).
