# Política de privacidad

## Recopilación de datos

El desarrollador no recopila ningún dato de esta aplicación.

### Información que no recopilamos

- Información personal
- Estadísticas de uso
- Información del dispositivo
- Datos de ubicación
- Contenido o metadatos de imágenes
- Historial de navegación
- Cualquier otro dato del usuario

### Extensión de Chrome

La extensión de Chrome de Nicasa solicita acceso al contenido de la página únicamente para extraer las URL de las imágenes con fines de visualización. La extensión:

- No lee ni almacena el historial de navegación
- No rastrea el comportamiento del usuario
- No transmite ningún dato a servidores externos
- Solo procesa las URL de las imágenes localmente en tu navegador

### Procesamiento local

Todo el procesamiento, la edición y la visualización de imágenes ocurren localmente en tu dispositivo. No se sube ninguna imagen ni dato a servidores externos.

### Permisos

Nicasa solicita los siguientes permisos en macOS:

- **Grabación de pantalla**: necesaria para la función de captura
- **Accesibilidad**: opcional, se usa para las funciones del modo superposición
- **Archivos y carpetas**: acceso a los directorios elegidos por el usuario para navegar por imágenes

Estos permisos se pueden gestionar en Ajustes del Sistema > Privacidad y seguridad.

### Servicios de terceros

Nicasa no se integra con ningún servicio de análisis, publicidad o recopilación de datos de terceros.

### Opciones de privacidad

Si deseas ejercer tus derechos de privacidad (por ejemplo: solicitudes de acceso, eliminación, portabilidad u oposición), o si crees que Nicasa tiene datos personales sobre ti, puedes enviar una solicitud mediante uno de los métodos siguientes:

- Correo electrónico: nicasa@w3cub.com
- Abrir una incidencia de privacidad: https://github.com/nicasa-app/nicasa-support/issues
- Usar nuestra página de Opciones de privacidad: /es/guide/privacy-choices

Dado que Nicasa no recopila datos personales como se describe arriba, muchas solicitudes se responderán confirmando que no se dispone de datos personales. Si en futuras versiones comenzamos a recopilar datos personales, esta página y el formulario de Opciones de privacidad ofrecerán una forma de enviar y hacer seguimiento de las solicitudes.

Nuestro objetivo es responder a las solicitudes de privacidad legítimas en un plazo de 30 días.

### Actualizaciones

Esta política de privacidad puede actualizarse con nuevas versiones de la aplicación. Se notificará a los usuarios cualquier cambio significativo.

### Contacto

Para cuestiones relacionadas con la privacidad, contáctanos a través del [repositorio de GitHub](https://github.com/nicasa-app/nicasa-support/issues).
