# 隐私政策

## 数据收集

开发者不会通过本应用收集任何数据。

### 我们不会收集的信息

- 个人信息
- 使用统计
- 设备信息
- 位置数据
- 图片内容或元数据
- 浏览记录
- 任何其他用户数据

### Chrome 扩展

Nicasa Chrome 扩展仅为实现看图功能而请求访问页面内容以提取图片地址。该扩展：

- 不会读取或存储浏览记录
- 不会追踪用户行为
- 不会向外部服务器传输任何数据
- 仅在浏览器本地处理图片地址

### 本地处理

所有图片处理、编辑与查看都在你的设备本地完成，不会把图片或数据上传到外部服务器。

### 权限

Nicasa 在 macOS 上请求以下权限：

- **屏幕录制**：截图功能所必需
- **辅助功能**：可选，用于悬浮模式相关功能
- **文件与文件夹**：访问用户选择的目录以浏览图片

这些权限可在「系统设置 > 隐私与安全性」中管理。

### 第三方服务

Nicasa 未接入任何第三方统计、广告或数据收集服务。

### 隐私选项

如果你想行使隐私权利（例如：查阅、删除、可携带或拒绝授权等请求），或你确信 Nicasa 持有关于你的个人数据，可通过以下任一方式提交请求：

- 邮箱：nicasa@w3cub.com
- 提交隐私 issue：https://github.com/nicasa-app/nicasa-support/issues
- 使用我们的隐私选项页面：/zh-CN/guide/privacy-choices

由于如上所述 Nicasa 并不收集个人数据，许多请求会以「未持有任何个人数据」的确认作为答复。如果未来的版本开始收集个人数据，本页面与隐私选项表单将提供提交与跟踪请求的途径。

我们力求在 30 天内回应合理的隐私请求。

### 更新

本隐私政策可能会随应用新版本而更新。如有重大变更，我们会通知用户。

### 联系我们

如对隐私有疑问，请通过 [GitHub 仓库](https://github.com/nicasa-app/nicasa-support/issues)联系我们。
