# 将 Nicasa 设为默认看图应用

按照以下简单步骤，让图片默认用 Nicasa 打开。

## 第 1 步 —— 右键点击图片文件
在 Finder 中找到任意 HEIC/HEIF 图片并右键点击它。

提示：右键点击任意 HEIC/HEIF 图片文件。

## 第 2 步 —— 选择「打开方式」
在上下文菜单中悬停在「打开方式」上。

提示：悬停在「打开方式」上。

## 第 3 步 —— 选择 Nicasa
在应用列表中选择 Nicasa。

提示：选择「Nicasa」。

## 第 4 步 —— 勾选「始终以此方式打开」
在对话框中勾选「始终以此方式打开」，然后点击「打开」。

提示：勾选「始终以这种方式打开 .heic 文件」。

## 第 5 步 —— 设置完成！
从现在起，你的图片都会用 Nicasa 打开。

提示：设置完成！尽情享受 Nicasa 吧。

## 第 6 步 —— 随时更改默认应用（可选）
日后如需更换默认应用：

右键点击任意图片 → 显示简介 → 打开方式 → 全部更改

提示：随时在 Finder 中更改：显示简介 → 打开方式 → 全部更改

![macOS：将 Nicasa 设为默认看图应用](/guide.png)

**注意**
如果在列表中找不到 Nicasa，请确认 Nicasa 已正确安装。你可能需要重新启动 Nicasa 后再试一次。
