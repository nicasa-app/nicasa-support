# 使用指南

## 基础导航

### 打开图片

- **文件菜单**：点击 文件 > 打开，选择单张图片
- **文件夹视图**：点击 文件 > 打开文件夹，浏览整个目录
- **拖拽**：把图片文件或文件夹直接拖到应用窗口中
- **Chrome 扩展**：在任意网站上点击扩展图标即可查看全部图片

## Finder 同步扩展

### 在 Finder 中快速处理图片

Finder 同步扩展会在 Finder 工具栏中添加一个 Nicasa 按钮，用于快速处理图片：

1. 在 Finder 中选中一张或多张图片
2. 点击 Nicasa 工具栏按钮
3. 选择 **图片优化器** 以压缩文件，或选择 **AI 图像编辑器** 以增强图片
4. Nicasa 会自动打开并处理选中的文件

### 支持的格式

该扩展支持：JPG、PNG、GIF、BMP、WebP、SVG、TIFF 和 ICO 文件。

### 缩略图视图

主界面以缩略图形式展示你的图片：

- **单击**：选中一张图片
- **双击**：以完整视图打开
- **右键**：呼出带选项的上下文菜单

### 完整视图模式

在全屏查看图片时：

- **缩放**：使用鼠标滚轮或缩放控件
- **平移**：在放大后的图片上按住拖动
- **切换**：使用方向键或屏幕按钮切换到上一张/下一张

## 截图功能

### 截图

1. 点击工具栏中的截图按钮，或使用键盘快捷键
2. 选择你想要截取的区域
3. 截图会自动在 Nicasa 中打开，方便立即编辑

### 屏幕录制权限

截图功能需要屏幕录制权限：

1. 进入 系统设置 > 隐私与安全性 > 屏幕录制
2. 勾选 Nicasa 旁边的复选框
3. 如有必要，重启 Nicasa

## AI 图像编辑器

### AI 编辑器概览

Nicasa 内置强大的 AI 图像增强工具：

- **自动增强**：自动提升画质
- **智能裁剪**：智能给出裁剪建议
- **色彩校正**：由 AI 驱动的色彩调整
- **降噪**：去除噪点与颗粒
- **锐化**：智能锐化且不产生伪影

### 图像修复（Inpainting）工具

修复工具可以帮你：

- 去除图片中不需要的物体
- 智能填补缺失部分
- 修复受损区域
- 清理背景

## 透明悬浮模式

为设计师与画师量身打造：

1. 在 Nicasa 中打开一张图片
2. 从「显示」菜单启用悬浮模式
3. 使用滑块调节透明度
4. 图片将始终浮于所有其他窗口之上
5. 可用于描图、参考对照或 UI 比对

## 键盘快捷键

| 快捷键 | 操作 |
|----------|--------|
| `Cmd+O` | 打开文件 |
| `Cmd+Shift+O` | 打开文件夹 |
| `Space` | 下一张图片 |
| `Shift+Space` | 上一张图片 |
| `Cmd+F` | 切换全屏 |
| `Cmd+W` | 关闭窗口 |
| `Cmd+Q` | 退出应用 |
| `Delete` | 删除当前图片 |
| `Cmd+S` | 截图 |
| `Cmd+E` | 打开 AI 编辑器 |
| `Cmd+T` | 切换悬浮模式 |

## Chrome 扩展联动

### 安装

1. 安装 [Nicasa Chrome 扩展](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. 扩展图标会出现在浏览器工具栏中

### 使用

1. 打开任意网站
2. 点击 Nicasa 扩展图标
3. 以网格形式查看该页面的所有图片
4. 点击任意图片，即可在 Nicasa 中打开
5. 对网页图片使用 Nicasa 的全部功能

## 设置

通过 Nicasa > 偏好设置进入设置：

- **通用**：默认文件夹、语言、主题
- **浏览**：缩略图尺寸、缩放行为、动画
- **编辑器**：AI 工具偏好、默认增强项
- **扩展**：Chrome 扩展设置
- **隐私**：数据收集偏好

## 支持的格式

Nicasa 支持所有常见图片格式：

- **标准格式**：JPEG、PNG、GIF、BMP、TIFF、WebP
- **RAW**：CR2、NEF、ARW、DNG（需转换）
- **矢量**：SVG（需栅格化）
- **动图**：GIF、APNG

- JPEG/JPG
- PNG
- GIF（静态）
- BMP
- TIFF
- WebP
- HEIC（在受支持的系统上）

## 技巧与提示

- 使用搜索栏按文件名快速查找图片
- 通过文件夹整理图片来创建图集
- 使用评分系统标记你喜欢的图片
- 通过「文件」菜单以不同格式导出图片
