# 安装

## 下载 Nicasa

Nicasa 仅通过 Mac App Store 提供 macOS 版本。应用售价 $4.99，一次性购买即可解锁全部功能。

### 下载方式

- **Mac App Store**：[下载 Nicasa](https://apps.apple.com/us/app/nicasa-image-viewer/id6756032669?mt=12) —— $4.99
- **Chrome 扩展**：[免费 Chrome 扩展](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj) —— 免费

## 安装步骤

### 通过 Mac App Store 安装

1. 点击上面的「下载 Nicasa」链接，或在 Mac App Store 中搜索「Nicasa」
2. 点击「获取」或「购买」完成付费（$4.99）
3. 应用会自动下载并安装
4. 从「应用程序」文件夹或启动台启动 Nicasa

### 安装 Chrome 扩展

1. 访问 [Chrome 应用商店页面](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. 点击「添加至 Chrome」
3. 在弹窗中确认安装
4. 扩展即会添加到你的浏览器

## 首次启动

第一次启动 Nicasa 时：

1. 系统会提示你授予必要权限（截图功能需要屏幕录制权限）
2. 应用会扫描「图片」文件夹中的图片
3. 你可以立即开始浏览图库
4. 建议安装 Chrome 扩展，以获得更完整的网页看图体验

### Finder 同步扩展

Nicasa 附带一个 Finder 工具栏扩展，用于快速处理图片：

1. 启动 Nicasa 后，进入**系统设置** → **扩展** → **访达扩展**
2. 启用 **Nicasa Finder Sync**
3. 在 Finder 工具栏上右键 → **自定义工具栏…**
4. 把 Nicasa 按钮拖到工具栏上

这样你就能直接在 Finder 里对选中的图片进行优化或编辑。

## 系统要求

- **macOS**：10.13 或更高版本
- **存储空间**：54.5 MB 可用空间
- **内存**：最低 4GB RAM，推荐 8GB

## 权限

Nicasa 需要以下权限：

- **屏幕录制**：用于截图功能（可稍后授予）
- **辅助功能**：用于悬浮模式相关功能（可选）
- **文件与文件夹**：访问「图片」文件夹及用户选择的目录

你可以随时在「系统设置 > 隐私与安全性」中修改这些权限。

## 安装故障排除

如果安装过程中遇到问题：

- 确认你拥有管理员/root 权限
- 检查系统是否满足最低要求
- 尝试重新下载安装包
- 如在 Linux 上安装，请确认已安装所需依赖

如需更多帮助，请访问我们的[问题反馈页](https://github.com/nicasa-project/nicasa-support/issues)。
