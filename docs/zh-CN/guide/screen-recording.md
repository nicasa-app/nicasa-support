# 屏幕录制权限指南（macOS）

## 为什么 Nicasa 需要屏幕录制权限？

在 macOS 上，截图与屏幕捕捉类应用必须获得屏幕录制权限，才能读取显示器上的像素。

从 macOS 10.15 Catalina 开始，Apple 引入了更严格的隐私保护。任何捕捉屏幕内容（包括截图）的应用都必须获得用户的明确授权。

这适用于所有应用，包括从 Mac App Store 下载的应用。

**没有该权限，Nicasa 无法截图或录制屏幕内容。**

## 如何开启屏幕录制权限

请按以下步骤操作：

1. 打开 **系统设置**
2. 进入 **隐私与安全性**
3. 选择 **屏幕录制**
4. 在列表中找到 **Nicasa** 并勾选

如果应用当时已在运行，请在授予权限后重启 Nicasa。

## 如果权限弹窗没有出现

权限对话框通常会在应用首次尝试捕捉屏幕时出现。

如果你没有看到该弹窗，可能是因为：

- 权限请求此前被拒绝过
- macOS 缓存了权限状态
- 应用在弹窗出现之前就执行了捕捉

这种情况下，你可能需要重置该权限。

## 重置屏幕录制权限

你可以在终端中使用以下命令重置权限：

```bash
tccutil reset ScreenCapture com.nicasa.nue
```

执行命令后：

1. 重启 Nicasa
2. 再次触发截图功能
3. macOS 应会重新弹出权限对话框

## 如果重置仍然无效

极少数情况下，macOS 可能会保留无效的权限状态。

如果重置权限没有解决问题，请尝试以下步骤：

1. 退出 Nicasa
2. 从「应用程序」文件夹中删除 Nicasa
3. 从 Mac App Store 重新安装最新版本
4. 再次启动应用
5. 当 macOS 请求屏幕录制权限时，选择 **允许**

重新安装应用可以促使 macOS 重建权限记录。

## 另一种手动修复方法

你也可以手动切换一次权限：

1. 打开 **系统设置**
2. 进入 **隐私与安全性**
3. 打开 **屏幕录制**
4. 取消勾选 Nicasa，然后重新勾选
5. 重启 Nicasa

## 安全说明

授予屏幕录制权限并不会让 Nicasa 控制你的系统。

它仅允许应用为截图与捕捉功能读取屏幕像素。

你可以随时在以下位置撤销该权限：
**系统设置 → 隐私与安全性 → 屏幕录制**
