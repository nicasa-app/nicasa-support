# 故障排除

## 常见问题

### 应用无法启动

**现象**：Nicasa 启动失败或立刻崩溃

**解决办法**：
1. 确认系统为 macOS 10.13 或更高版本
2. 确认至少拥有 4GB 内存
3. 重启你的 Mac
4. 从 Mac App Store 重新安装 Nicasa
5. 检查是否存在冲突的应用

### 截图无法使用

**现象**：截图功能不工作

**解决办法**：
1. **授予屏幕录制权限**：
   - 进入 系统设置 > 隐私与安全性 > 屏幕录制
   - 勾选 Nicasa 旁边的复选框
   - 重启 Nicasa
2. 确认没有其他截图工具正在运行
3. 尝试重启你的 Mac

### Chrome 扩展无法使用

**现象**：扩展不显示或无法提取图片

**解决办法**：
1. 确认扩展已在 Chrome 中启用
2. 检查 Chrome 版本是否兼容
3. 尝试刷新网页
4. 重新安装扩展
5. 清除浏览器缓存与 Cookie

### 图片无法加载

**现象**：缩略图不显示或图片打不开

**解决办法**：
1. 检查图片文件的访问权限
2. 确认图片文件未损坏
3. 确认格式受支持（JPEG、PNG、GIF、BMP、TIFF、WebP）
4. 尝试重新打开该文件夹
5. 重启 Nicasa

### 性能缓慢

**现象**：应用卡顿或缩略图加载很慢

**解决办法**：
1. 关闭其他占用内存较多的应用
2. 确保有充足的可用内存（推荐 8GB）
3. 在偏好设置中调小缩略图网格尺寸
4. 清理应用缓存
5. 重启你的 Mac

### AI 编辑器无法使用

**现象**：AI 编辑工具不可用或不工作

**解决办法**：
1. 确认网络连接稳定（部分功能需要联网）
2. 检查你的 Mac 是否满足最低要求
3. 重启 Nicasa
4. 更新到最新版本
5. 如问题依旧，请联系支持

### 权限问题

**现象**：应用请求权限，或某些功能不可用

**解决办法**：
1. **屏幕录制**：系统设置 > 隐私与安全性 > 屏幕录制
2. **辅助功能**：系统设置 > 隐私与安全性 > 辅助功能（用于悬浮模式）
3. **文件与文件夹**：系统设置 > 隐私与安全性 > 文件与文件夹
4. 授予权限后重启 Nicasa

### 悬浮模式问题

**现象**：透明悬浮模式工作不正常

**解决办法**：
1. 在系统设置中授予辅助功能权限
2. 确认没有其他悬浮类工具正在运行
3. 尝试关闭再重新开启悬浮模式
4. 重启 Nicasa

## 错误提示

### “需要屏幕录制权限”

**解决办法**：按上文「截图无法使用」一节所述授予屏幕录制权限。

### “无法加载图片”

**可能原因**：
- 文件已损坏
- 格式不受支持
- 文件权限问题
- 文件过大

**解决办法**：
1. 尝试用「预览」打开该文件，确认它是否有效
2. 转换为受支持的格式
3. 检查文件权限
4. 确认为合理的文件体积

### “扩展无响应”

**解决办法**：刷新网页后重试。如果反复出现，请重新安装扩展。

## 进阶故障排除

### 查看日志

访问应用日志：

1. 进入 帮助 > 显示日志
2. 或在以下位置查找日志：
   - Windows：`%APPDATA%\Nicasa\logs`
   - macOS：`~/Library/Application Support/Nicasa/logs`
   - Linux：`~/.config/Nicasa/logs`

### 重置应用

将所有设置恢复为默认值：

1. 关闭 Nicasa
2. 删除应用数据文件夹
3. 重启 Nicasa

### 命令行选项

面向进阶用户，Nicasa 支持命令行参数：

```bash
nicasa --verbose          # 启用详细日志
nicasa --reset-settings   # 重置所有设置
nicasa /path/to/folder    # 打开指定文件夹
```
