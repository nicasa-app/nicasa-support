# 简介

## 关于 Nicasa

Nicasa 是一款现代桌面图片查看与截图工具，以速度、简洁和强大的编辑能力为设计目标。它专为 macOS 打造，把顺滑、现代的看图体验带到你的桌面。

## 核心功能

### 🖼️ **更好的看图方式**
干净专注的界面让图片瞬间呈现。没有干扰，没有杂乱——只有你的内容，在打开的那一刻被优雅地呈现。

### 📸 **截图与捕捉**
几秒内截取屏幕任意区域。快速而精确的截图工具内建于 Nicasa，保存与分享视觉灵感从未如此简单。

### 🤖 **AI 图像编辑**
用强大的 AI 工具增强与修饰图片。从快速调整到智能编辑，Nicasa 帮你轻松完成图像变身。

### 🔍 **透明悬浮模式**
设计师与画师的利器：把图片置顶于所有窗口之上，并可调节透明度——非常适合描图、参考对照和 UI 比对。

### 🌐 **Chrome 扩展联动**
与 Nicasa Chrome 扩展无缝衔接，在一个界面里查看任意网站上的全部图片。随时提取、浏览并直接在 Nicasa 中打开图片，获得更快、更沉浸的看图体验。

### 🎨 **顺滑直观的设计**
由新一代技术驱动，Nicasa 带来流畅的转场、清晰的渲染和体贴的交互设计。

## 系统要求

- **操作系统**：macOS 10.13 或更高版本
- **内存**：最低 4GB RAM，推荐 8GB
- **存储空间**：安装需要 54.5 MB
- **显示**：最低 1280x720 分辨率

## 支持的语言

Nicasa 支持多种语言，包括英语、简体中文、繁体中文、日语、法语、韩语、德语、西班牙语、意大利语、越南语、泰语、印地语、土耳其语、俄语、葡萄牙语、荷兰语、德语（瑞士）、芬兰语、马来语、希腊语、挪威语、印尼语、匈牙利语、丹麦语和乌克兰语。
