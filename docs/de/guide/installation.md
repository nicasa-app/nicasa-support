# Installation

## Nicasa herunterladen

Nicasa ist ausschließlich für macOS über den Mac App Store erhältlich. Die App kostet 4,99 $ und bietet einen einmaligen Kauf mit Zugriff auf alle Funktionen.

### Download-Optionen

- **Mac App Store**: [Nicasa herunterladen](https://apps.apple.com/us/app/nicasa-image-viewer/id6756032669?mt=12) —— 4,99 $
- **Chrome-Erweiterung**: [Kostenlose Chrome-Erweiterung](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj) —— Kostenlos

## Installationsschritte

### Installation über den Mac App Store

1. Klicke auf den obigen Link „Nicasa herunterladen“ oder suche im Mac App Store nach „Nicasa“
2. Klicke auf „Laden“ oder „Kaufen“, um die App zu erwerben (4,99 $)
3. Die App wird automatisch heruntergeladen und installiert
4. Starte Nicasa aus dem Ordner „Programme“ oder über das Launchpad

### Installation der Chrome-Erweiterung

1. Besuche die [Seite im Chrome Web Store](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. Klicke auf „Zu Chrome hinzufügen“
3. Bestätige die Installation im Popup
4. Die Erweiterung wird deinem Browser hinzugefügt

## Erster Start

Wenn du Nicasa zum ersten Mal startest:

1. Du wirst aufgefordert, die nötigen Berechtigungen zu erteilen (Bildschirmaufnahme für Screenshots)
2. Die App durchsucht deinen Bilderordner nach Bildern
3. Du kannst sofort mit dem Durchsehen deiner Sammlung beginnen
4. Erwäge die Installation der Chrome-Erweiterung für ein besseres Weberlebnis

### Finder-Sync-Erweiterung

Nicasa enthält eine Erweiterung für die Finder-Symbolleiste zur schnellen Bildverarbeitung:

1. Gehe nach dem Start von Nicasa zu **Systemeinstellungen** → **Erweiterungen** → **Finder-Erweiterungen**
2. Aktiviere **Nicasa Finder Sync**
3. Rechtsklicke auf die Finder-Symbolleiste → **Symbolleiste anpassen …**
4. Ziehe die Nicasa-Schaltfläche in die Symbolleiste

So kannst du ausgewählte Bilder direkt aus dem Finder optimieren oder bearbeiten.

## Systemanforderungen

- **macOS**: 10.13 oder neuer
- **Speicherplatz**: 54,5 MB freier Speicher
- **Arbeitsspeicher**: mindestens 4 GB RAM, 8 GB empfohlen

## Berechtigungen

Nicasa benötigt folgende Berechtigungen:

- **Bildschirmaufnahme**: für die Screenshot-Funktion (kann später erteilt werden)
- **Bedienungshilfen**: für Funktionen des Overlay-Modus (optional)
- **Dateien und Ordner**: Zugriff auf den Bilderordner und von dir ausgewählte Verzeichnisse

Du kannst diese Berechtigungen jederzeit unter Systemeinstellungen > Datenschutz & Sicherheit ändern.

## Installationsprobleme beheben

Wenn bei der Installation Probleme auftreten:

- Stelle sicher, dass du Administrator-/Root-Rechte hast
- Prüfe, ob dein System die Mindestanforderungen erfüllt
- Versuche, die Datei erneut herunterzuladen
- Stelle unter Linux sicher, dass die nötigen Abhängigkeiten installiert sind

Weitere Hilfe findest du auf unserer [Issues-Seite](https://github.com/nicasa-project/nicasa-support/issues).
