# 画面収録の権限ガイド（macOS）

## Nicasa に画面収録の権限が必要な理由

macOS では、スクリーンショットや画面キャプチャを行うアプリは、ディスプレイからピクセルを読み取るために画面収録の権限を取得する必要があります。

macOS 10.15 Catalina 以降、Apple はより厳格なプライバシー保護を導入しました。画面の内容をキャプチャするアプリ（スクリーンショットを含む）は、すべてユーザーの明示的な承認が必要です。

これは Mac App Store からダウンロードしたアプリを含む、すべてのアプリに適用されます。

**この権限がないと、Nicasa はスクリーンショットの撮影や画面の録画ができません。**

## 画面収録の権限を有効にする方法

次の手順に従ってください：

1. **システム設定** を開きます
2. **プライバシーとセキュリティ** に移動します
3. **画面収録** を選択します
4. 一覧から **Nicasa** を見つけてチェックを入れます

アプリがすでに起動していた場合は、権限を有効にした後に Nicasa を再起動してください。

## 権限のダイアログが表示されなかった場合

権限のダイアログは通常、アプリが初めて画面をキャプチャしようとしたときに表示されます。

ダイアログが表示されなかった場合、次のいずれかが原因と考えられます：

- 権限の要求が以前に拒否された
- macOS が権限の状態をキャッシュしている
- ダイアログが表示される前にアプリがキャプチャを実行した

この場合は、権限をリセットする必要があります。

## 画面収録の権限をリセットする

ターミナルで次のコマンドを実行すると権限をリセットできます：

```bash
tccutil reset ScreenCapture com.nicasa.nue
```

コマンドを実行した後：

1. Nicasa を再起動します
2. スクリーンショット機能を再度実行します
3. macOS が権限のダイアログを再表示します

## リセットしても解決しない場合

まれに、macOS が無効な権限の状態を保持していることがあります。

権限のリセットで問題が解決しない場合は、次の手順をお試しください：

1. Nicasa を終了します
2. アプリケーションフォルダから Nicasa を削除します
3. Mac App Store から最新版を再インストールします
4. アプリを再度起動します
5. macOS が画面収録の権限を求めたら **許可** を選択します

アプリを再インストールすると、macOS に権限のエントリを再作成させることができます。

## 別の手動修正方法

権限を手動で切り替えることもできます：

1. **システム設定** を開きます
2. **プライバシーとセキュリティ** に移動します
3. **画面収録** を開きます
4. Nicasa のチェックを外し、もう一度チェックを入れます
5. Nicasa を再起動します

## セキュリティに関する注意

画面収録の権限を付与しても、Nicasa がシステムを操作できるようになるわけではありません。

スクリーンショットとキャプチャ機能のために、画面のピクセルを読み取ることだけが許可されます。

この権限は次の場所でいつでも取り消せます：
**システム設定 → プライバシーとセキュリティ → 画面収録**
