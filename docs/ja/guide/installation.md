# インストール

## Nicasa のダウンロード

Nicasa は Mac App Store を通じて macOS 版のみ提供されています。アプリは $4.99 の買い切りで、すべての機能を利用できます。

### ダウンロード方法

- **Mac App Store**：[Nicasa をダウンロード](https://apps.apple.com/us/app/nicasa-image-viewer/id6756032669?mt=12) —— $4.99
- **Chrome 拡張機能**：[無料 Chrome 拡張機能](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj) —— 無料

## インストール手順

### Mac App Store からのインストール

1. 上記の「Nicasa をダウンロード」リンクをクリックするか、Mac App Store で「Nicasa」を検索します
2. 「入手」または「購入」をクリックして購入します（$4.99）
3. アプリが自動的にダウンロード・インストールされます
4. アプリケーションフォルダまたは Launchpad から Nicasa を起動します

### Chrome 拡張機能のインストール

1. [Chrome ウェブストアのページ](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)にアクセスします
2. 「Chrome に追加」をクリックします
3. ポップアップでインストールを確認します
4. 拡張機能がブラウザに追加されます

## 初回起動

Nicasa を初めて起動したとき：

1. 必要な権限の付与を求められます（スクリーンショットには画面収録の権限が必要です）
2. アプリが「ピクチャ」フォルダ内の画像をスキャンします
3. すぐにコレクションの閲覧を開始できます
4. ウェブ閲覧を強化するため、Chrome 拡張機能のインストールもご検討ください

### Finder 同期拡張機能

Nicasa には画像を素早く処理するための Finder ツールバー拡張機能が含まれています：

1. Nicasa を起動したら、**システム設定** → **機能拡張** → **Finder 機能拡張** を開きます
2. **Nicasa Finder Sync** を有効にします
3. Finder のツールバーを右クリック → **ツールバーをカスタマイズ…**
4. Nicasa のボタンをツールバーにドラッグします

これにより、Finder から直接選択した画像を最適化・編集できます。

## システム要件

- **macOS**：10.13 以降
- **ストレージ**：54.5 MB の空き容量
- **メモリ**：最低 4GB RAM、8GB 推奨

## 権限

Nicasa は以下の権限を必要とします：

- **画面収録**：スクリーンショット機能に使用（後から許可できます）
- **アクセシビリティ**：オーバーレイモードの機能に使用（任意）
- **ファイルとフォルダ**：「ピクチャ」フォルダおよびユーザーが選択したディレクトリへのアクセス

これらの権限は「システム設定 > プライバシーとセキュリティ」でいつでも変更できます。

## インストールのトラブルシューティング

インストール中に問題が発生した場合：

- 管理者（root）権限があることを確認してください
- システムが最低要件を満たしているか確認してください
- ファイルを再ダウンロードしてみてください
- Linux の場合は、必要な依存関係がインストールされているか確認してください

さらにサポートが必要な場合は、[Issues ページ](https://github.com/nicasa-project/nicasa-support/issues)をご覧ください。
