# トラブルシューティング

## よくある問題

### アプリが起動しない

**症状**：Nicasa の起動に失敗する、またはすぐにクラッシュする

**解決方法**：
1. macOS 10.13 以降で実行していることを確認してください
2. 少なくとも 4GB の RAM があることを確認してください
3. Mac を再起動してください
4. Mac App Store から Nicasa を再インストールしてください
5. 競合するアプリケーションがないか確認してください

### スクリーンショットが動作しない

**症状**：スクリーンショット機能が動作しない

**解決方法**：
1. **画面収録の権限を付与する**：
   - システム設定 > プライバシーとセキュリティ > 画面収録 に移動します
   - Nicasa の横のチェックボックスをオンにします
   - Nicasa を再起動します
2. 他のスクリーンショットツールが動作していないことを確認してください
3. Mac を再起動してみてください

### Chrome 拡張機能が動作しない

**症状**：拡張機能が表示されない、または画像を抽出しない

**解決方法**：
1. Chrome で拡張機能が有効になっていることを確認してください
2. 互換性のあるバージョンの Chrome を使用しているか確認してください
3. ウェブページを再読み込みしてみてください
4. 拡張機能を再インストールしてください
5. ブラウザのキャッシュと Cookie をクリアしてください

### 画像が読み込まれない

**症状**：サムネイルが表示されない、または画像が開かない

**解決方法**：
1. 画像ファイルのアクセス権を確認してください
2. 画像が破損していないことを確認してください
3. 対応形式（JPEG、PNG、GIF、BMP、TIFF、WebP）であることを確認してください
4. フォルダをもう一度開いてみてください
5. Nicasa を再起動してください

### 動作が遅い

**症状**：アプリの反応が鈍い、またはサムネイルの読み込みが遅い

**解決方法**：
1. メモリを多く使う他のアプリを閉じてください
2. 十分な空きメモリを確保してください（8GB 推奨）
3. 環境設定でサムネイルのグリッドサイズを小さくしてください
4. アプリのキャッシュをクリアしてください
5. Mac を再起動してください

### AI エディターが動作しない

**症状**：AI 編集ツールが利用できない、または機能しない

**解決方法**：
1. 安定したインターネット接続を確認してください（一部の機能で必要です）
2. Mac が最低要件を満たしているか確認してください
3. Nicasa を再起動してください
4. 最新バージョンに更新してください
5. 問題が続く場合はサポートにお問い合わせください

### 権限の問題

**症状**：アプリが権限を要求する、または一部の機能が動作しない

**解決方法**：
1. **画面収録**：システム設定 > プライバシーとセキュリティ > 画面収録
2. **アクセシビリティ**：システム設定 > プライバシーとセキュリティ > アクセシビリティ（オーバーレイモード用）
3. **ファイルとフォルダ**：システム設定 > プライバシーとセキュリティ > ファイルとフォルダ
4. 権限を付与した後に Nicasa を再起動してください

### オーバーレイモードの問題

**症状**：透明オーバーレイモードが正しく動作しない

**解決方法**：
1. システム設定でアクセシビリティの権限を付与してください
2. 他のオーバーレイ系ツールが動作していないことを確認してください
3. オーバーレイモードをオフにしてから再度オンにしてみてください
4. Nicasa を再起動してください

## エラーメッセージ

### 「画面収録の権限が必要です」

**解決方法**：上記の「スクリーンショットが動作しない」セクションの手順で画面収録の権限を付与してください。

### 「画像を読み込めませんでした」

**考えられる原因**：
- ファイルが破損している
- 対応していない形式
- ファイルのアクセス権の問題
- ファイルが大きすぎる

**解決方法**：
1. 「プレビュー」アプリでファイルを開き、有効かどうか確認してください
2. 対応形式に変換してください
3. ファイルのアクセス権を確認してください
4. ファイルサイズが妥当か確認してください

### 「拡張機能が応答しません」

**解決方法**：ウェブページを再読み込みして再試行してください。繰り返し発生する場合は、拡張機能を再インストールしてください。

## サポートを受ける

問題が解決しない場合：

1. このトラブルシューティングガイドを確認してください
2. [よくある質問](/ja/guide/faq)をご覧ください
3. [GitHub](https://github.com/nicasa-app/nicasa-support/issues) で issue を報告してください
4. macOS のバージョン、Nicasa のバージョン、問題を再現する詳細な手順を記載してください

## システム情報

問題を報告する際は、以下を含めてください：

- macOS のバージョン（Apple メニュー > この Mac について）
- Nicasa のバージョン（Nicasa > Nicasa について）
- Mac のモデルとチップ（Apple シリコンまたは Intel）
- 問題を再現する手順
- 表示されたエラーメッセージ

これは通常、画像ファイルが移動または削除されたことを意味します。フォルダを再度開くか、別のディレクトリを選択してみてください。

### 「対応していない形式です」

画像形式が認識されません。[対応形式](/ja/guide/usage)の一覧を確認するか、互換性のある形式に変換してください。

### 「メモリが不足しています」

システムの RAM が不足しています。他のアプリを閉じるか、メモリを増設してください。

## 高度なトラブルシューティング

### ログの表示

アプリのログにアクセスするには：

1. ヘルプ > ログを表示 に移動します
2. または次の場所でログを確認できます：
   - Windows：`%APPDATA%\Nicasa\logs`
   - macOS：`~/Library/Application Support/Nicasa/logs`
   - Linux：`~/.config/Nicasa/logs`

### アプリのリセット

すべての設定を既定値に戻すには：

1. Nicasa を終了します
2. アプリのデータフォルダを削除します
3. Nicasa を再起動します

### コマンドラインオプション

上級者向けに、Nicasa はコマンドライン引数に対応しています：

```bash
nicasa --verbose          # 詳細ログを有効にする
nicasa --reset-settings   # すべての設定をリセットする
nicasa /path/to/folder    # 指定したフォルダを開く
```

## さらにサポートが必要な場合

これらの解決方法で問題が解決しない場合：

1. [よくある質問](/ja/guide/faq)をご覧ください
2. 既存の [issues](https://github.com/nicasa-project/nicasa-support/issues) を検索してください
3. 新しい issue を作成し、以下を記載してください：
   - オペレーティングシステムとバージョン
   - Nicasa のバージョン
   - 問題を再現する手順
   - エラーメッセージやスクリーンショット
