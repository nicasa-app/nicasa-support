## 規約への同意

Nicasa（以下「本アプリ」）をダウンロード、インストール、または使用することにより、あなたは本利用規約（以下「本規約」）に拘束されることに同意したものとみなされます。本規約に同意されない場合は、本アプリを使用しないでください。

## サービスの説明

Nicasa は macOS 向けのデスクトップ画像ビューア兼スクリーンショットツールで、以下を提供します：

- 画像の閲覧・ブラウズ機能
- スクリーンショットと画面キャプチャ機能
- AI による画像編集ツール
- ウェブ画像抽出用の Chrome ブラウザ拡張機能
- デザイン作業向けの透明オーバーレイモード

## ライセンスと使用権

### Mac App Store 版
- $4.99 の買い切り購入が必要
- お客様の Apple ID に関連付けられたデバイスでの使用が許諾されます
- ファミリー共有に対応

### Chrome 拡張機能
- 無料でダウンロード・使用できます
- Chrome ウェブストアの利用規約に従います
