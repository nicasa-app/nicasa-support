# プライバシーポリシー

## データの収集

開発者は本アプリからいかなるデータも収集しません。

### 収集しない情報

- 個人情報
- 利用統計
- デバイス情報
- 位置情報
- 画像の内容やメタデータ
- 閲覧履歴
- その他のユーザーデータ

### Chrome 拡張機能

Nicasa Chrome 拡張機能は、画像閲覧機能のために画像 URL を抽出する目的に限り、ページコンテンツへのアクセスを要求します。この拡張機能は：

- 閲覧履歴を読み取ったり保存したりしません
- ユーザーの行動を追跡しません
- 外部サーバーにいかなるデータも送信しません
- 画像 URL をブラウザ内でローカルに処理するだけです

### ローカル処理

画像の処理、編集、閲覧はすべて端末上で行われます。画像やデータが外部サーバーにアップロードされることはありません。

### 権限

Nicasa は macOS で以下の権限を要求します：

- **画面収録**：スクリーンショット機能に必要
- **アクセシビリティ**：任意、オーバーレイモードの機能に使用
- **ファイルとフォルダ**：画像閲覧のためユーザーが選択したディレクトリへのアクセス

これらの権限は「システム設定 > プライバシーとセキュリティ」で管理できます。

### 第三者サービス

Nicasa は第三者による分析、広告、データ収集サービスを一切組み込んでいません。

### プライバシーの選択

プライバシーに関する権利（アクセス、削除、ポータビリティ、オプトアウトの各請求など）を行使したい場合、または Nicasa があなたに関する個人データを保有しているとお考えの場合は、以下のいずれかの方法で請求を送信できます：

- メール：nicasa@w3cub.com
- プライバシー issue の作成：https://github.com/nicasa-app/nicasa-support/issues
- 公開しているプライバシー選択ページの利用：/ja/guide/privacy-choices

上述のとおり Nicasa は個人データを収集しないため、多くの請求は「個人データを保有していない」旨の確認をもって回答されます。将来のリリースで個人データの収集を開始した場合は、本ページとプライバシー選択フォームが請求の送信と追跡の手段を提供します。

正当なプライバシー請求には 30 日以内に回答するよう努めます。

### 更新

本プライバシーポリシーはアプリの新バージョンに伴い更新される場合があります。重要な変更がある場合はユーザーに通知します。
