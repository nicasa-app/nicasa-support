# Nicasa を既定の画像ビューアに設定する

以下の簡単な手順で、画像を既定で Nicasa で開けるようにします。

## ステップ 1 —— 画像ファイルを右クリック
Finder で任意の HEIC/HEIF 画像を見つけ、右クリックします。

ヒント：任意の HEIC/HEIF 画像ファイルを右クリックします。

## ステップ 2 —— 「このアプリケーションで開く」を選択
コンテキストメニューの「このアプリケーションで開く」にカーソルを合わせます。

ヒント：「このアプリケーションで開く」にカーソルを合わせます。

## ステップ 3 —— Nicasa を選択
アプリケーションの一覧から Nicasa を選びます。

ヒント：「Nicasa」を選択します。

## ステップ 4 —— 「常にこのアプリケーションで開く」にチェック
ダイアログで「常にこのアプリケーションで開く」にチェックを入れ、「開く」をクリックします。

ヒント：「.heic ファイルを常にこのアプリケーションで開く」にチェックを入れます。

## ステップ 5 —— 設定完了！
これ以降、画像は Nicasa で開くようになります。

ヒント：設定完了！Nicasa をお楽しみください。

## ステップ 6 —— いつでも既定アプリを変更（任意）
後で既定アプリを変更するには：

任意の画像を右クリック → 情報を見る → このアプリケーションで開く → すべてを変更

ヒント：Finder でいつでも変更できます：情報を見る → このアプリケーションで開く → すべてを変更

![macOS：Nicasa を既定の画像ビューアに設定](/guide.png)

**注意**
一覧に Nicasa が表示されない場合は、Nicasa が正しくインストールされているか確認してください。Nicasa を再起動してからもう一度お試しください。
