# プライバシーの選択

本ページでは、Nicasa へのプライバシー請求の送信方法と、その後に期待できる対応について説明します。

## 対象となる内容

本ページは、個人データへのアクセス、削除、ポータビリティの請求、または特定のデータ利用からのオプトアウト（該当する場合の「販売しないでください」請求など）に使用できます。

注記：Nicasa は現在、個人データを収集・保存していません（プライバシーポリシーをご参照ください）。当社があなたに関する個人データを保有しているとお考えの場合は、請求を送信してください。調査いたします。

## 請求の送信方法

効率的に処理するため、請求の際に以下の情報をご提供ください：

- お名前
- 連絡先メールアドレス
- 請求内容の説明（アクセス、削除、ポータビリティ、オプトアウト）
- 記録の特定に役立つ情報（サポートチケット ID など）

請求は以下のいずれかに送信してください：

- メール：nicasa@w3cub.com
- プライバシー issue の作成：https://github.com/nicasa-app/nicasa-support/issues

## 回答までの期間

有効な請求には 30 日以内に確認と回答を行うよう努めます。さらに時間が必要な場合は、想定される期間をお知らせします。

## 個人データを保有していない場合

Nicasa は画像をローカルで処理し、ユーザーデータを収集しない設計であるため、多くの請求は「個人データを保有していない」旨の確認をもって終了します。個人データが収集された証拠をご提供いただければ、調査し適切な対応を行います。

## 販売しないでください / オプトアウト

特定の法域の権利（CCPA/CPRA など）に基づきデータの販売からのオプトアウトを行使する場合で、当社があなたの個人データを販売したとお考えの場合は、請求の中で状況を説明してください。個人データを販売していない場合は、その旨を回答で確認します。

## お問い合わせ

本手続きについてご質問がある場合は、nicasa@w3cub.com までご連絡いただくか、https://github.com/nicasa-app/nicasa-support/issues で issue を作成してください。
