# よくある質問

## 一般的な質問

### Nicasa とは何ですか？

Nicasa は macOS 専用に設計された、モダンなデスクトップ画像ビューア兼スクリーンショットツールです。クリーンで反応の良いインターフェースで画像コレクションを素早く直感的に閲覧でき、強力な AI 編集機能も備えています。

### Nicasa は無料ですか？

Chrome 拡張機能は完全無料でダウンロード・利用できます。macOS アプリはすべての機能を利用するために $4.99 の買い切り購入が必要です。

### 対応しているオペレーティングシステムは？

Nicasa は現在 macOS 10.13 以降専用です。Windows 版と Linux 版は現時点では提供していません。

### Nicasa はどうやって更新しますか？

更新は Mac App Store を通じて行われます。新しいバージョンが利用可能になると通知され、App Store アプリから直接更新できます。

## 使い方の質問

### Nicasa でスクリーンショットを撮るには？

1. Nicasa を起動します
2. ツールバーのスクリーンショットボタンをクリックするか、`Cmd+S` を押します
3. キャプチャしたい領域を選択します
4. スクリーンショットが Nicasa で開き、すぐに編集できます

### ウェブ画像を扱えますか？

はい！無料の Nicasa Chrome 拡張機能をインストールすると：
- 任意のウェブサイトのすべての画像を 1 か所で閲覧できます
- 画像をその場で抽出して閲覧できます
- Nicasa で直接画像を開き、より快適に閲覧できます

### どのような AI 編集機能がありますか？

Nicasa には強力な AI ツールが組み込まれています：
- **自動補正**：画質を自動的に向上
- **スマート切り抜き**：インテリジェントな切り抜き提案
- **インペイント**：不要なオブジェクトをインテリジェントに削除
- **色補正**：AI による色調整
- **ノイズ除去**：ノイズや粒状感を除去

### 透明オーバーレイモードはどう動作しますか？

デザイナーやアーティストに最適です：
- 画像を調整可能な透明度で他のすべてのウィンドウの前面に固定
- トレース、参照資料との照合、UI 比較に利用
- すべてのアプリケーションにわたって位置を保持

## 技術的な質問

### なぜ画面収録の権限が必要なのですか？

スクリーンショット機能には画面収録の権限が必要です。これにより、スクリーンショットツールを使用したときに Nicasa が画面をキャプチャできます。

### オフラインで Nicasa を使えますか？

はい。macOS アプリはローカル画像ファイルに対して完全にオフラインで動作します。Chrome 拡張機能によるウェブ画像の抽出にはインターネット接続が必要です。

### 対応している macOS のバージョンは？

Nicasa は macOS 10.13 以降に対応しています。Apple シリコンに最適化され、M シリーズチップ上でネイティブに動作します。

### Chrome 拡張機能にはどの権限が必要ですか？

この拡張機能は画像 URL を抽出する目的に限り、ページコンテンツへのアクセスを要求します。閲覧履歴の読み取りや保存は行いません。

### データはどこかにアップロードされますか？

いいえ。すべての処理は端末上で行われます。Nicasa が画像を収集・送信・保存することはありません。

### 設定をバックアップするには？

設定はローカルに保存されます。バックアップ方法：
1. Nicasa > 環境設定 に移動します
2. 対応していれば設定を書き出します
3. またはアプリの環境設定フォルダを手動でバックアップします

設定はアプリのデータフォルダに保存されています。このフォルダをコピーしてバックアップしてください。

### ポータブル版はありますか？

Windows 版にはポータブル版があります。当社のウェブサイトからダウンロードできます。

## 開発に関する質問

### Nicasa に貢献できますか？

[GitHub リポジトリ](https://github.com/nicasa-project/nicasa-support)にアクセスして、コードの提供、問題の報告、機能の提案ができます。

### ソースから Nicasa をビルドするには？

ビルド手順については GitHub の開発者向けドキュメントをご覧ください。

### Nicasa はどの技術を使っていますか？

Nicasa は Electron によるデスクトップラッパーと Vue.js によるインターフェースを含む、モダンなウェブ技術で構築されています。

## プライバシーに関する質問

### Nicasa はデータを収集しますか？

いいえ。Nicasa は個人データを収集・送信しません。すべての画像処理は端末上で行われます。

### 私の画像は安全ですか？

はい。Nicasa は明示的に開いた画像にのみアクセスします。ファイルをアップロードしたり共有したりすることはありません。

### Nicasa にはどの権限が必要ですか？

Nicasa は画像の読み取りと設定の保存のためにファイルシステムへのアクセスが必要です。動作にインターネット接続は必要ありません。
