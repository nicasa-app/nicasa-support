# はじめに

## Nicasa について

Nicasa は、スピード・シンプルさ・強力な編集機能を重視して設計された、モダンなデスクトップ画像ビューア兼スクリーンショットツールです。macOS 専用に作られており、滑らかでモダンな画像閲覧体験をデスクトップにもたらします。

## 主な機能

### 🖼️ **より良い画像閲覧**
クリーンで集中できるインターフェースで画像を一瞬で表示。雑念も乱雑さもなく、開いた瞬間にコンテンツが美しく現れます。

### 📸 **スクリーンショットとキャプチャ**
画面の任意の部分を数秒で撮影。高速で正確なスクリーンショットツールが Nicasa に組み込まれており、ビジュアルアイデアの保存と共有がこれまでになく簡単です。

### 🤖 **AI 画像エディター**
強力な AI ツールで画像を強化・調整。簡単な補正からインテリジェントな編集まで、Nicasa が画像の変化を手軽に実現します。

### 🔍 **透明オーバーレイモード**
デザイナーやアーティストに最適なツール：画像をすべてのウィンドウの最前面に固定し、透明度を調整できます。トレース、参照資料との照合、UI 比較に最適です。

### 🌐 **Chrome 拡張機能との連携**
Nicasa Chrome 拡張機能とシームレスに連携し、あらゆるウェブサイトの画像を 1 か所で閲覧できます。画像をその場で抽出・閲覧し、Nicasa で直接開けるため、より高速で没入感のある閲覧体験が得られます。

### 🎨 **滑らかで直感的なデザイン**
次世代技術を搭載し、流動的なトランジション、鮮明なレンダリング、細やかな配慮の行き届いたインタラクションを提供します。

## システム要件

- **オペレーティングシステム**：macOS 10.13 以降
- **メモリ**：最低 4GB RAM、8GB 推奨
- **ストレージ**：インストールに 54.5 MB
- **ディスプレイ**：最低 1280x720 の解像度

## 対応言語

Nicasa は多言語に対応しています：英語、簡体字中国語、繁体字中国語、日本語、フランス語、韓国語、ドイツ語、スペイン語、イタリア語、ベトナム語、タイ語、ヒンディー語、トルコ語、ロシア語、ポルトガル語、オランダ語、ドイツ語（スイス）、フィンランド語、マレー語、ギリシャ語、ノルウェー語、インドネシア語、ハンガリー語、デンマーク語、ウクライナ語。
