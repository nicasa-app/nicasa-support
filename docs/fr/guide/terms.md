## Description du service

Nicasa est une visionneuse d'images de bureau et un outil de capture d'écran pour macOS qui propose :

- des capacités de visualisation et de navigation d'images
- des fonctionnalités de capture d'écran
- des outils d'édition d'images par IA
- une extension de navigateur Chrome pour extraire des images web
- un mode superposition transparente pour le travail de design
