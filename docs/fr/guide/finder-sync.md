# Extension de synchronisation Finder

## Présentation

L'extension de synchronisation Nicasa Finder ajoute un bouton dans la barre d'outils du Finder de macOS, vous permettant de traiter rapidement vos fichiers image sans ouvrir l'application principale Nicasa.

### Fonctionnalités

- **Optimiseur d'images** : compresse et optimise les images sélectionnées
- **Éditeur d'images par IA** : édite les images sélectionnées avec l'IA (réparation, amélioration, remplissage, etc.)
- **Accès rapide depuis la barre d'outils du Finder**
- **Fonctionne avec plusieurs images sélectionnées**

## Installation et configuration

### Installation via l'application Nicasa

L'extension de synchronisation est incluse avec l'application principale Nicasa. Après avoir installé l'application, activez l'extension :

1. Ouvrez **Réglages Système** > **Extensions** > **Extensions du Finder**
2. Activez **Nicasa Finder Sync**

### Bouton de la barre d'outils

Une fois activée, une icône Nicasa apparaît dans la barre d'outils du Finder.

Si elle n'est pas visible :
1. Faites un clic droit sur la barre d'outils du Finder
2. Sélectionnez **Personnaliser la barre d'outils…**
3. Faites glisser le bouton Nicasa à l'emplacement voulu

## Utiliser le bouton de la barre d'outils du Finder

### Sélectionner des fichiers

Ouvrez le Finder et sélectionnez une ou plusieurs images. Formats pris en charge :
- `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp`, `.svg`, `.tiff`, `.ico`

### Utiliser le menu

Cliquez sur le bouton Nicasa de la barre d'outils, puis choisissez :

| Option | Description |
|--------|-------------|
| **Optimiseur d'images** | Compresse et optimise les images sélectionnées |
| **Éditeur d'images par IA** | Ouvre les images sélectionnées dans l'éditeur IA de Nicasa pour les réparer, les améliorer ou les retoucher |

> ⚠️ **Remarque** : si aucun fichier n'est sélectionné, le bouton émet un bip et l'action ne s'exécute pas.

### Flux de travail

1. Sélectionnez des images dans le Finder
2. Cliquez sur le bouton Nicasa de la barre d'outils → choisissez l'action souhaitée
3. L'application Nicasa s'ouvre automatiquement et traite les images sélectionnées

## Conseils

- Pour de meilleurs résultats, sélectionnez des images dans un dossier auquel vous avez accès
- Vous pouvez sélectionner plusieurs fichiers à la fois
- Si une image ne s'ouvre pas, vérifiez qu'elle fait partie des formats pris en charge
- L'extension s'intègre parfaitement au bac à sable de macOS : vous ne devez autoriser l'accès qu'une seule fois
