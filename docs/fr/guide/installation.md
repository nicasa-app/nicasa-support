# Installation

## Télécharger Nicasa

Nicasa est disponible exclusivement pour macOS via le Mac App Store. L'application coûte 4,99 $ et propose un achat unique donnant accès à toutes les fonctionnalités.

### Options de téléchargement

- **Mac App Store** : [Télécharger Nicasa](https://apps.apple.com/us/app/nicasa-image-viewer/id6756032669?mt=12) —— 4,99 $
- **Extension Chrome** : [Extension Chrome gratuite](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj) —— Gratuit

## Étapes d'installation

### Installation via le Mac App Store

1. Cliquez sur le lien « Télécharger Nicasa » ci-dessus ou recherchez « Nicasa » dans le Mac App Store
2. Cliquez sur « Obtenir » ou « Acheter » pour acquérir l'application (4,99 $)
3. L'application se télécharge et s'installe automatiquement
4. Lancez Nicasa depuis le dossier Applications ou le Launchpad

### Installation de l'extension Chrome

1. Rendez-vous sur la [page du Chrome Web Store](https://chromewebstore.google.com/detail/nicasa-image-viewer/cihceekeiedkinpjjjfehlgjdhpeokbj)
2. Cliquez sur « Ajouter à Chrome »
3. Confirmez l'installation dans la fenêtre qui s'ouvre
4. L'extension est ajoutée à votre navigateur

## Premier lancement

Lors du premier lancement de Nicasa :

1. Il vous sera demandé d'accorder les autorisations nécessaires (enregistrement de l'écran pour les captures)
2. L'application analyse votre dossier Images à la recherche d'images
3. Vous pouvez immédiatement parcourir votre collection
4. Pensez à installer l'extension Chrome pour améliorer la navigation web

### Extension de synchronisation Finder

Nicasa inclut une extension de barre d'outils du Finder pour traiter rapidement vos images :

1. Après avoir lancé Nicasa, allez dans **Réglages Système** → **Extensions** → **Extensions du Finder**
2. Activez **Nicasa Finder Sync**
3. Faites un clic droit sur la barre d'outils du Finder → **Personnaliser la barre d'outils…**
4. Faites glisser le bouton Nicasa dans la barre d'outils

Vous pourrez ainsi optimiser ou éditer les images sélectionnées directement depuis le Finder.

## Configuration requise

- **macOS** : 10.13 ou version ultérieure
- **Stockage** : 54,5 Mo d'espace disponible
- **Mémoire** : 4 Go de RAM minimum, 8 Go recommandés

## Autorisations

Nicasa nécessite les autorisations suivantes :

- **Enregistrement de l'écran** : pour la fonction de capture (peut être accordée plus tard)
- **Accessibilité** : pour les fonctions du mode superposition (facultatif)
- **Fichiers et dossiers** : accès au dossier Images et aux répertoires choisis par l'utilisateur

Vous pouvez modifier ces autorisations à tout moment dans Réglages Système > Confidentialité et sécurité.

## Dépannage de l'installation

Si vous rencontrez des problèmes lors de l'installation :

- Vérifiez que vous disposez des privilèges administrateur/root
- Vérifiez que votre système répond à la configuration minimale
- Essayez de télécharger à nouveau le fichier
- Sous Linux, vérifiez que les dépendances requises sont installées

Pour plus d'aide, consultez notre [page des problèmes](https://github.com/nicasa-project/nicasa-support/issues).
