# Politique de confidentialité

## Collecte de données

Le développeur ne collecte aucune donnée via cette application.

### Informations que nous ne collectons pas

- Informations personnelles
- Statistiques d'utilisation
- Informations sur l'appareil
- Données de localisation
- Contenu ou métadonnées des images
- Historique de navigation
- Toute autre donnée utilisateur

### Extension Chrome

L'extension Chrome de Nicasa demande l'accès au contenu des pages uniquement pour extraire les URL des images dans le cadre de la fonction de visualisation. L'extension :

- ne lit ni ne stocke l'historique de navigation
- ne suit pas le comportement des utilisateurs
- ne transmet aucune donnée à des serveurs externes
- traite uniquement les URL d'images localement dans votre navigateur

### Traitement local

Tout le traitement, l'édition et la visualisation des images se font localement sur votre appareil. Aucune image ni donnée n'est envoyée à des serveurs externes.

### Autorisations

Nicasa demande les autorisations suivantes sous macOS :

- **Enregistrement de l'écran** : nécessaire pour la fonction de capture
- **Accessibilité** : facultatif, utilisé pour les fonctions du mode superposition
- **Fichiers et dossiers** : accès aux répertoires choisis par l'utilisateur pour parcourir les images

Ces autorisations peuvent être gérées dans Réglages Système > Confidentialité et sécurité.

### Services tiers

Nicasa n'intègre aucun service tiers d'analyse, de publicité ou de collecte de données.

### Options de confidentialité

Si vous souhaitez exercer vos droits en matière de confidentialité (par exemple : demandes d'accès, de suppression, de portabilité ou d'opposition), ou si vous pensez que Nicasa détient des données personnelles vous concernant, vous pouvez soumettre une demande par l'un des moyens suivants :

- E-mail : nicasa@w3cub.com
- Ouvrir un ticket de confidentialité : https://github.com/nicasa-app/nicasa-support/issues
- Utiliser notre page Options de confidentialité : /fr/guide/privacy-choices

Étant donné que Nicasa ne collecte pas de données personnelles comme décrit ci-dessus, de nombreuses demandes recevront une confirmation qu'aucune donnée personnelle n'est détenue. Si nous commençons à collecter des données personnelles dans de futures versions, cette page et le formulaire Options de confidentialité permettront de soumettre et de suivre les demandes.

Nous nous efforçons de répondre aux demandes légitimes dans un délai de 30 jours.

### Mises à jour

Cette politique de confidentialité peut être mise à jour avec les nouvelles versions de l'application. Les utilisateurs seront informés de tout changement important.

### Contact

Pour toute question relative à la confidentialité, contactez-nous via le [dépôt GitHub](https://github.com/nicasa-app/nicasa-support/issues).
