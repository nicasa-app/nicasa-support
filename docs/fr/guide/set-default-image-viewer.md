# Définir Nicasa comme visionneuse d'images par défaut

Suivez ces étapes simples pour ouvrir vos images avec Nicasa par défaut.

## Étape 1 —— Faites un clic droit sur un fichier image
Trouvez une image HEIC/HEIF dans le Finder et faites un clic droit dessus.

Conseil : faites un clic droit sur n'importe quel fichier image HEIC/HEIF.

## Étape 2 —— Choisissez « Ouvrir avec »
Survolez « Ouvrir avec » dans le menu contextuel.

Conseil : survolez « Ouvrir avec ».

## Étape 3 —— Sélectionnez Nicasa
Choisissez Nicasa dans la liste des applications.

Conseil : sélectionnez « Nicasa ».

## Étape 4 —— Cochez « Toujours ouvrir avec »
Dans la boîte de dialogue, cochez « Toujours ouvrir avec » puis cliquez sur « Ouvrir ».

Conseil : cochez « Toujours ouvrir les fichiers .heic avec ».

## Étape 5 —— Tout est prêt !
Désormais, vos images s'ouvriront avec Nicasa.

Conseil : tout est prêt ! Bonne utilisation de Nicasa.

## Étape 6 —— Changer l'application par défaut à tout moment (facultatif)
Pour modifier l'application par défaut plus tard :

Clic droit sur une image → Lire les informations → Ouvrir avec → Tout modifier

Conseil : modifiable à tout moment dans le Finder : Lire les informations → Ouvrir avec → Tout modifier

![macOS : définir Nicasa comme visionneuse d'images par défaut](/guide.png)

**Remarque**
Si Nicasa n'apparaît pas dans la liste, vérifiez que Nicasa est correctement installé. Il peut être nécessaire de relancer Nicasa et de réessayer.
