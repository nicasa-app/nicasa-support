# Questions fréquentes

## Questions générales

### Qu'est-ce que Nicasa ?

Nicasa est une visionneuse d'images de bureau moderne et un outil de capture d'écran conçu exclusivement pour macOS. Il offre une navigation rapide et intuitive dans vos collections d'images, avec une interface claire et réactive, ainsi que de puissantes capacités d'édition par IA.

### Nicasa est-il gratuit ?

L'extension Chrome est entièrement gratuite. L'application macOS nécessite un achat unique de 4,99 $ pour accéder à toutes les fonctionnalités.

### Quels systèmes d'exploitation sont pris en charge ?

Nicasa est actuellement disponible exclusivement pour macOS 10.13 ou version ultérieure. Les versions Windows et Linux ne sont pas disponibles pour le moment.

### Comment mettre à jour Nicasa ?

Les mises à jour passent par le Mac App Store. Vous serez notifié lorsque des mises à jour sont disponibles et pourrez les installer directement depuis l'application App Store.

## Questions d'utilisation

### Comment prendre des captures d'écran avec Nicasa ?

1. Lancez Nicasa
2. Cliquez sur le bouton de capture dans la barre d'outils ou utilisez `Cmd+S`
3. Sélectionnez la zone à capturer
4. La capture s'ouvre dans Nicasa pour une édition immédiate

### Nicasa fonctionne-t-il avec les images web ?

Oui ! Installez l'extension Chrome gratuite de Nicasa pour :
- voir toutes les images de n'importe quel site web au même endroit
- extraire et parcourir les images instantanément
- ouvrir les images directement dans Nicasa pour une meilleure visualisation

### Quelles fonctionnalités d'édition par IA sont disponibles ?

Nicasa inclut de puissants outils d'IA :
- **Amélioration automatique** : améliore automatiquement la qualité de l'image
- **Recadrage intelligent** : suggestions intelligentes de recadrage
- **Retouche** : supprime intelligemment les objets indésirables
- **Correction des couleurs** : ajustements de couleur pilotés par l'IA
- **Réduction du bruit** : élimine le bruit et le grain

### Comment fonctionne le mode superposition transparente ?

Parfait pour les designers et les artistes :
- épinglez des images au-dessus de toutes les fenêtres avec une transparence réglable
- utilisez-le pour le décalquage, le travail de référence ou la comparaison d'interfaces
- conserve sa position dans toutes les applications

## Questions techniques

### Pourquoi dois-je accorder l'autorisation d'enregistrement de l'écran ?

L'autorisation d'enregistrement de l'écran est nécessaire pour la fonction de capture. Elle permet à Nicasa de capturer votre écran lorsque vous utilisez l'outil de capture.

### Puis-je utiliser Nicasa hors ligne ?

Oui. L'application macOS fonctionne entièrement hors ligne pour les fichiers image locaux. L'extraction d'images web via l'extension Chrome nécessite une connexion internet.

### Quelles versions de macOS sont prises en charge ?

Nicasa prend en charge macOS 10.13 ou version ultérieure. Il est optimisé pour Apple Silicon et s'exécute nativement sur les puces de la série M.

### Quelles autorisations l'extension Chrome demande-t-elle ?

L'extension demande l'accès au contenu des pages uniquement pour extraire les URL des images. Aucun historique de navigation n'est lu ni stocké.

### Mes données sont-elles envoyées quelque part ?

Non. Tout le traitement se fait localement sur votre appareil. Nicasa ne collecte, ne transmet ni ne stocke vos images.

### Comment sauvegarder mes réglages ?

Vos réglages sont stockés localement. Pour les sauvegarder :
1. Allez dans Nicasa > Préférences
2. Exportez vos réglages si l'option est disponible
3. Ou sauvegardez manuellement le dossier des préférences de l'application

Les réglages sont stockés dans le dossier de données de l'application. Copiez ce dossier pour sauvegarder vos préférences.

### Existe-t-il une version portable ?

Une version portable est disponible pour Windows. Téléchargez-la depuis notre site web.

### Puis-je contribuer à Nicasa ?

Rendez-vous sur notre [dépôt GitHub](https://github.com/nicasa-project/nicasa-support) pour contribuer au code, signaler des problèmes ou proposer des fonctionnalités.

Consultez notre documentation développeur sur GitHub pour les instructions de compilation.

### Quelles technologies Nicasa utilise-t-il ?

Nicasa est construit avec des technologies web modernes, dont Electron pour l'enveloppe de bureau et Vue.js pour l'interface.

## Questions de confidentialité

### Nicasa collecte-t-il des données ?

Non, Nicasa ne collecte ni ne transmet aucune donnée personnelle. Tout le traitement des images se fait localement sur votre appareil.

### Mes images sont-elles en sécurité ?

Oui. Nicasa n'accède qu'aux images que vous ouvrez explicitement. Il ne téléverse ni ne partage vos fichiers.

### Quelles autorisations Nicasa nécessite-t-il ?

Nicasa a besoin d'accéder à votre système de fichiers pour lire les images et enregistrer les réglages. Aucun accès internet n'est nécessaire pour fonctionner.
