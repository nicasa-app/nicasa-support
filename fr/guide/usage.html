Guide d'utilisation ​

Navigation de base ​

Ouvrir des images ​

  • Menu Fichier : cliquez sur Fichier > Ouvrir pour sélectionner des images individuelles
  • Vue par dossier : cliquez sur Fichier > Ouvrir un dossier pour parcourir un répertoire entier
  • Glisser-déposer : faites glisser des fichiers image ou des dossiers directement dans la fenêtre de l'application
  • Extension Chrome : cliquez sur l'icône de l'extension sur n'importe quel site web pour voir toutes les images

Extension de synchronisation Finder ​

Traitement rapide des images depuis le Finder ​

L'extension de synchronisation ajoute un bouton Nicasa dans la barre d'outils du Finder pour traiter rapidement les images :

  1. Sélectionnez une ou plusieurs images dans le Finder
  2. Cliquez sur le bouton Nicasa de la barre d'outils
  3. Choisissez Optimiseur d'images pour compresser les fichiers ou Éditeur d'images par IA pour améliorer les images
  4. Nicasa s'ouvre automatiquement et traite les fichiers sélectionnés

Formats pris en charge ​

L'extension fonctionne avec les fichiers JPG, PNG, GIF, BMP, WebP, SVG, TIFF et ICO.

Vue miniatures ​

L'interface principale affiche des miniatures de vos images :

  • Clic : sélectionner une image
  • Double-clic : ouvrir en vue complète
  • Clic droit : accéder au menu contextuel avec les options

Mode d'affichage complet ​

Lors de la visualisation d'une image en plein écran :

  • Zoom : utilisez la molette de la souris ou les contrôles de zoom
  • Déplacement : cliquez et faites glisser pour vous déplacer dans les images agrandies
  • Navigation : utilisez les flèches ou les boutons à l'écran pour passer à l'image suivante ou précédente

Fonction de capture d'écran ​

Prendre des captures d'écran ​

  1. Cliquez sur le bouton de capture dans la barre d'outils ou utilisez le raccourci clavier
  2. Sélectionnez la zone à capturer
  3. La capture s'ouvre automatiquement dans Nicasa pour être éditée

Autorisation d'enregistrement de l'écran ​

Pour la fonction de capture, Nicasa a besoin de l'autorisation d'enregistrement de l'écran :

  1. Allez dans Réglages Système > Confidentialité et sécurité > Enregistrement de l'écran
  2. Cochez la case en face de Nicasa
  3. Redémarrez Nicasa si nécessaire

Éditeur d'images par IA ​

Présentation de l'éditeur par IA ​

Nicasa inclut de puissants outils d'IA pour améliorer les images :

  • Amélioration automatique : améliore automatiquement la qualité de l'image
  • Recadrage intelligent : suggestions intelligentes de recadrage
  • Correction des couleurs : ajustements de couleur pilotés par l'IA
  • Réduction du bruit : élimine le bruit et le grain
  • Netteté : accentuation intelligente sans artefacts

Outil de retouche (inpainting) ​

L'outil de retouche vous permet de :

  • supprimer des objets indésirables des images
  • combler intelligemment les parties manquantes
  • restaurer des zones endommagées
  • nettoyer les arrière-plans

Mode superposition transparente ​

Parfait pour les designers et les artistes :

  1. Ouvrez une image dans Nicasa
  2. Activez le mode superposition depuis le menu Présentation
  3. Ajustez la transparence avec le curseur
  4. L'image reste au-dessus de toutes les autres fenêtres
  5. Utilisez-la pour le décalquage, le travail de référence ou la comparaison d'interfaces

Intégration de l'extension Chrome ​

Installation ​

  1. Installez l'extension Chrome Nicasa
  2. L'icône de l'extension apparaît dans la barre d'outils de votre navigateur

Utilisation ​

  1. Visitez n'importe quel site web
  2. Cliquez sur l'icône de l'extension Nicasa
  3. Toutes les images de la page s'affichent dans une grille
  4. Cliquez sur une image pour l'ouvrir dans Nicasa
  5. Utilisez toutes les fonctionnalités de Nicasa sur les images web

Réglages ​

Accédez aux réglages via Nicasa > Préférences :

  • Général : dossier par défaut, langue, thème
  • Affichage : taille des miniatures, comportement du zoom, animations
  • Éditeur : préférences des outils d'IA, améliorations par défaut
  • Extensions : réglages de l'extension Chrome
  • Confidentialité : préférences de collecte de données

Formats pris en charge ​

Nicasa prend en charge tous les formats d'image courants :

  • Standard : JPEG, PNG, GIF, BMP, TIFF, WebP

  • RAW : CR2, NEF, ARW, DNG (avec conversion)

  • Vectoriel : SVG (avec rastérisation)

  • Animés : GIF, APNG

  • JPEG/JPG

  • PNG

  • GIF (statique)

  • BMP

  • TIFF

  • WebP

  • HEIC (sur les systèmes compatibles)

Astuces et conseils ​

  • Utilisez la barre de recherche pour trouver rapidement des images par nom de fichier
  • Créez des collections en organisant vos images dans des dossiers
  • Utilisez le système de notation pour marquer vos images favorites
  • Exportez vos images dans différents formats depuis le menu Fichier
