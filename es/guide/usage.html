Guía de uso ​

Navegación básica ​

Abrir imágenes ​

  • Menú Archivo: haz clic en Archivo > Abrir para seleccionar imágenes individuales
  • Vista de carpeta: haz clic en Archivo > Abrir carpeta para explorar un directorio completo
  • Arrastrar y soltar: arrastra archivos de imagen o carpetas directamente a la ventana de la aplicación
  • Extensión de Chrome: haz clic en el icono de la extensión en cualquier sitio web para ver todas las imágenes

Extensión de sincronización con el Finder ​

Procesamiento rápido de imágenes desde el Finder ​

La extensión de sincronización añade un botón de Nicasa a la barra de herramientas del Finder para procesar imágenes rápidamente:

  1. Selecciona una o varias imágenes en el Finder
  2. Haz clic en el botón de Nicasa de la barra de herramientas
  3. Elige Optimizador de imágenes para comprimir archivos o Editor de imágenes con IA para mejorar imágenes
  4. Nicasa se abrirá automáticamente y procesará los archivos seleccionados

Formatos compatibles ​

La extensión funciona con archivos JPG, PNG, GIF, BMP, WebP, SVG, TIFF e ICO.

Vista de miniaturas ​

La interfaz principal muestra miniaturas de tus imágenes:

  • Clic: selecciona una imagen
  • Doble clic: abre en vista completa
  • Clic derecho: accede al menú contextual con opciones

Modo de vista completa ​

Al ver una imagen a pantalla completa:

  • Zoom: usa la rueda del ratón o los controles de zoom
  • Desplazamiento: haz clic y arrastra para moverte por imágenes ampliadas
  • Navegación: usa las teclas de flecha o los botones en pantalla para ir a la imagen siguiente o anterior

Función de captura de pantalla ​

Hacer capturas ​

  1. Haz clic en el botón de captura de la barra de herramientas o usa el atajo de teclado
  2. Selecciona el área que quieres capturar
  3. La captura se abrirá automáticamente en Nicasa para editarla

Permiso de grabación de pantalla ​

Para la función de captura, Nicasa necesita el permiso de grabación de pantalla:

  1. Ve a Ajustes del Sistema > Privacidad y seguridad > Grabación de pantalla
  2. Marca la casilla junto a Nicasa
  3. Reinicia Nicasa si es necesario

Editor de imágenes con IA ​

Descripción del editor de IA ​

Nicasa incluye potentes herramientas de IA para mejorar imágenes:

  • Mejora automática: mejora la calidad de la imagen automáticamente
  • Recorte inteligente: sugerencias inteligentes de recorte
  • Corrección de color: ajustes de color impulsados por IA
  • Reducción de ruido: elimina el ruido y el grano
  • Enfoque: enfoque inteligente sin artefactos

Herramienta de relleno (inpainting) ​

La herramienta de relleno te permite:

  • Eliminar objetos no deseados de las imágenes
  • Rellenar partes faltantes de forma inteligente
  • Restaurar áreas dañadas
  • Limpiar fondos

Modo superposición transparente ​

Perfecto para diseñadores y artistas:

  1. Abre una imagen en Nicasa
  2. Activa el modo superposición desde el menú Visualización
  3. Ajusta la transparencia con el control deslizante
  4. La imagen se mantendrá por encima de todas las demás ventanas
  5. Úsalo para calcar, consultar referencias o comparar interfaces

Integración con la extensión de Chrome ​

Instalación ​

  1. Instala la extensión de Chrome de Nicasa
  2. El icono de la extensión aparecerá en la barra de herramientas del navegador

Uso ​

  1. Visita cualquier sitio web
  2. Haz clic en el icono de la extensión de Nicasa
  3. Verás todas las imágenes de la página en una cuadrícula
  4. Haz clic en cualquier imagen para abrirla en Nicasa
  5. Usa todas las funciones de Nicasa con imágenes web

Ajustes ​

Accede a los ajustes desde Nicasa > Preferencias:

  • General: carpeta predeterminada, idioma, tema
  • Visualización: tamaño de miniaturas, comportamiento del zoom, animaciones
  • Editor: preferencias de herramientas de IA, mejoras predeterminadas
  • Extensiones: ajustes de la extensión de Chrome
  • Privacidad: preferencias de recopilación de datos

Formatos compatibles ​

Nicasa admite todos los formatos de imagen habituales:

  • Estándar: JPEG, PNG, GIF, BMP, TIFF, WebP

  • RAW: CR2, NEF, ARW, DNG (con conversión)

  • Vectorial: SVG (con rasterización)

  • Animados: GIF, APNG

  • JPEG/JPG

  • PNG

  • GIF (estático)

  • BMP

  • TIFF

  • WebP

  • HEIC (en sistemas compatibles)

Consejos y trucos ​

  • Usa la barra de búsqueda para encontrar imágenes por nombre de archivo
  • Crea colecciones organizando imágenes en carpetas
  • Usa el sistema de valoraciones para marcar tus imágenes favoritas
  • Exporta imágenes en distintos formatos desde el menú Archivo
