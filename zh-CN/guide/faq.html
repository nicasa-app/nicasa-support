常见问题 ​

通用问题 ​

Nicasa 是什么？ ​

Nicasa 是一款专为 macOS 打造的现代桌面图片查看与截图工具。它以干净、响应迅速的界面提供快速直观的图片浏览，并具备强大的 AI 编辑能力。

Nicasa 免费吗？ ​

Chrome 扩展完全免费，可随意下载使用。macOS 应用需一次性支付 $4.99，才能解锁全部功能。

支持哪些操作系统？ ​

Nicasa 目前仅支持 macOS 10.13 或更高版本，暂不提供 Windows 与 Linux 版本。

如何更新 Nicasa？ ​

更新通过 Mac App Store 进行。有新版本时会收到通知，也可以直接在 App Store 应用中更新。

使用问题 ​

如何用 Nicasa 截图？ ​

  1. 启动 Nicasa
  2. 点击工具栏中的截图按钮，或使用 Cmd+S
  3. 选择你想要截取的区域
  4. 截图会在 Nicasa 中打开，可立即编辑

Nicasa 能处理网页图片吗？ ​

可以！安装免费的 Nicasa Chrome 扩展即可：

  • 在一个地方查看任意网站的所有图片
  • 随时提取并浏览图片
  • 直接在 Nicasa 中打开图片，获得更好的查看体验

有哪些 AI 编辑功能？ ​

Nicasa 内置强大的 AI 工具：

  • 自动增强：自动提升画质
  • 智能裁剪：智能裁剪建议
  • 图像修复：智能去除不需要的物体
  • 色彩校正：由 AI 驱动的色彩调整
  • 降噪：去除噪点与颗粒

透明悬浮模式是如何工作的？ ​

为设计师与画师量身打造：

  • 把图片以可调透明度置顶于所有窗口之上
  • 可用于描图、参考对照或 UI 比对
  • 在所有应用中保持位置不变

技术问题 ​

为什么需要授予屏幕录制权限？ ​

截图功能需要屏幕录制权限，这样 Nicasa 才能在你使用截图工具时捕捉屏幕。

可以离线使用 Nicasa 吗？ ​

可以。macOS 应用可完全离线处理本地图片文件；通过 Chrome 扩展提取网页图片则需要网络连接。

支持哪些 macOS 版本？ ​

Nicasa 支持 macOS 10.13 或更高版本，并针对 Apple 芯片优化，在 M 系列芯片上原生运行。

Chrome 扩展需要哪些权限？ ​

该扩展仅为提取图片地址而请求读取页面内容，不会读取或存储浏览记录。

我的数据会被上传吗？ ​

不会。所有处理都在你的设备本地完成，Nicasa 不会收集、传输或存储你的图片。

如何备份我的设置？ ​

设置保存在本地。备份方法：

  1. 进入 Nicasa > 偏好设置
  2. 如支持，导出你的设置
  3. 或手动备份应用偏好设置文件夹

设置存储在应用数据文件夹中，复制该文件夹即可完成备份。

有便携版吗？ ​

Windows 版本提供便携版，可从我们的网站下载。

开发问题 ​

我可以为 Nicasa 贡献代码吗？ ​

访问我们的 GitHub 仓库，贡献代码、反馈问题或提出功能建议。

如何从源码构建 Nicasa？ ​

请参阅 GitHub 上的开发者文档以获取构建说明。

Nicasa 使用了哪些技术？ ​

Nicasa 使用现代 Web 技术构建，桌面端封装使用 Electron，界面使用 Vue.js。

隐私问题 ​

Nicasa 会收集任何数据吗？ ​

不会。Nicasa 不收集也不传输任何个人数据，所有图片处理都在你的设备本地完成。

我的图片安全吗？ ​

安全。Nicasa 只会访问你主动打开的图片，不会上传或分享你的文件。

Nicasa 需要哪些权限？ ​

Nicasa 需要访问文件系统以读取图片和保存设置，运行时不依赖网络。

还有疑问？ ​

如果在这里找不到答案，请：

  1. 查阅我们的完整文档
  2. 搜索我们的 GitHub issues
  3. 如有需要，新建一个 issue

我们随时为你提供帮助！
